# stat-analysis — 真实案例参考

本文件收录 4 个真实研究咨询案例，原始背景是胰腺外科血管侵犯研究的统计建模诊断。每个案例附"通用原则"段落映射到其他领域。

**SKILL 主体讲泛化原则；本文件用于"看到模型输出 / 诊断异常时找类比"。**

案例之间存在叙事关系：SA-A（用户慌"主暴露不显著"）→ SA-B（去掉某协变量后又显著了）是连贯的两幕；SA-C 和 SA-D 是另一条独立线（围术期 logistic）。

## 案例 SA-A：不显著结果的诊断与解读

### 用户场景（原始）

用户跑完 OS 多因素 Cox 临床模型，把 `summary()` 结果贴出来，第一句话是"出来血管侵犯没有统计学意义啊，可以解释吗？"。关键输出：

```
                                       exp(coef)  lower .95  upper .95
age                                    1.023      1.010      1.035
log_CA199                              1.079      1.023      1.139
surgical_approachLaparoscopic          0.550      0.373      0.810
vascular_invasionBorderline / Contact  1.152      0.851      1.560
vascular_invasionDefinite VI           1.283      0.966      1.704
```

主暴露 `vascular_invasion` 的两个非参考水平 HR 都 > 1，但 CI 跨 1，p > 0.05。N = 474。

### 用户的初始反应 / 困惑

用户把"CI 跨 1"直接读成"无效 / 没意义 / 假设不成立"，担心整个研究废了。常见的连锁误读：
- "HR 1.28 但不显著" → "血管侵犯没用"
- 想直接得到二元判断（有用 / 没用），忽视方向、效应量、CI 上下限位置

### 关键判断 / 诊断逻辑

**信号**：HR 方向一致（No VI < Borderline 1.15 < Definite 1.28），都 > 1；Definite VI 的 CI 上限是 1.704，下限 0.966 紧贴 1；样本量中等（N=474）。

**第一步：先把"不显著"翻译成更精准的描述**
不要说"没意义"，应该说"在当前样本量和当前协变量集下，主暴露呈风险升高趋势但未达传统统计学显著"。CI 下限 0.966 ≈ 1 是关键信号——再多一点把握度可能就显著了，属于"边缘性阳性趋势"而非"完全阴性"。

**第二步：枚举 5 种合理原因（不是诡辩，是真诊断）**

1. **强协变量吸走效应**：模型里 CA19-9（HR 1.079，已显著）是肿瘤生物学侵袭性的强代理；血管侵犯严重的患者本身 CA19-9 更高 → 部分独立效应被 CA19-9 解释掉。
2. **暴露变量本身的非差异性错分**：三分类血管侵犯基于术中记录归纳，Borderline 组主观性强，会把真实效应往 1 拉。
3. **样本量 / 事件数边缘**：三分类暴露分散了每组的事件数，HR 方向对但 CI 宽。
4. **协变量代理了选择偏倚**：`surgical_approach` HR 0.55 显著保护——但微创组天然是简单病例，这个变量不只是"入路"，还承载病例筛选信息（见 SA-B）。
5. **真实生物学**：长期 OS 可能更多由病理负荷（T/N/grade/R）决定，血管侵犯只是其中一个非最强的独立因子。

**第三步：论文里怎么写**
不写"无影响"。写：
> 在多因素 Cox 临床模型中，与 No VI 组相比，Borderline / Contact 组和 Definite VI 组的死亡风险均呈升高趋势，但未达到统计学显著性（HR 分别为 1.152 [95% CI 0.851–1.560] 和 1.283 [95% CI 0.966–1.704]）。

讨论里坦诚 5 种原因里 2-3 条最贴的，不要全堆。

**第四步：下一步行动（不是认输，是补做分析）**
- 跑单因素 Cox 看血管侵犯单独的效应（多因素被吸走 vs 单因素也无信号是两种解释）
- 三分类的整体联合检验：`anova(mod0, mod_full, test = "Chisq")` —— 单层 p 值不显著时整体 p 仍可能显著
- 趋势检验（把 0/1/2 当有序连续）—— 三分组有梯度时这个特别有力
- **去掉嫌疑协变量的敏感性分析**（这就是 SA-B 的引子）

### 最终方案

主分析保留原模型，加：(a) 单因素 Cox（透明展示效应来源）、(b) 趋势检验（论文亮点）、(c) 去除可疑协变量的敏感性模型（SA-B）。论文写"边缘性阳性趋势"+"5 因素中最贴本研究的 2-3 条"+"病理校正模型作为下一步验证"。

### 通用原则 — 适用于

**通用诊断模式：主暴露 HR/OR 不显著时，按 4 步走**
1. 看 CI 下限离 1 多远（< 0.05 = 边缘信号；> 0.2 = 真的弱）
2. 看方向是否符合先验（方向对 = 信号存在但被稀释；方向反 = 警惕共线性 / 混杂）
3. 枚举可能的稀释源（强协变量 / 错分 / 样本量 / 选择偏倚 / 真生物学）
4. 论文写"trend toward"而不是"no effect"

**其他领域类比**：
- **教育研究**：干预措施对成绩的效应在多因素回归里 β=0.08, p=0.07，CI 跨 0。同样套路：先看是否有"基线认知能力"这种强协变量吸走干预效应。
- **市场 / A/B 实验**：feature 上线后 CTR 提升边缘不显著（p=0.08）—— 不要直接 ship/kill，看效应方向、CI 下限位置、是否被某个高度相关的并发实验吸走。
- **流行病学环境暴露**：空气污染对慢病住院的 OR 在校正吸烟 + SES 后变不显著——同样问"吸烟是不是把暴露效应吃了一部分"。

### SKILL 应用提示

**触发本案例的用户输出特征**：
- 用户贴出 Cox / logistic / 线性回归 summary，主暴露 HR/OR/β CI 跨 1（或跨 0）
- 用户问"为什么不显著"、"是不是没意义了"、"这样还能写论文吗"
- HR 方向是预期方向，CI 下限接近 1（如 0.95–1.10）

**Claude 应做的事**：先复述 HR 方向 + CI 上下限位置；不要急着说"换 Firth"或"加变量"；按 4 步诊断走；提醒用户跑单因素 + 整体联合检验 + 趋势检验；引导到 SA-B（去某协变量看变化）作为下一步。

## 案例 SA-B：协变量"吸走"主效应（敏感性分析揭示混杂结构）

> 紧接 SA-A：用户按建议去掉 `surgical_approach` 后重跑。

### 用户场景（原始）

用户来消息："去掉入路之后有意义了？"贴新输出：

```
                                       exp(coef)  lower .95  upper .95
age                                    1.021      1.009      1.034
log_CA199                              1.079      1.022      1.139
vascular_invasionBorderline / Contact  1.209      0.896      1.630
vascular_invasionDefinite VI           1.424      1.081      1.875
```

Definite VI 从 HR 1.283 (0.966–1.704) 变成 1.424 (1.081–1.875) —— **CI 不再跨 1，达显著**。

### 用户的初始反应 / 困惑

用户隐含的意图是"那我就把入路删掉吧，主分析直接用这个"。这是**为显著性删变量**的危险冲动，必须在论文方法学层面挡住。

### 关键判断 / 诊断逻辑

**信号**：单一协变量去掉后主暴露 HR 方向不变（仍 > 1）但点估计上调（1.28 → 1.42）+ CI 不再跨 1。这个变化模式特征非常明确——`surgical_approach` 不是中性混杂，它在吃主暴露的效应。

**为什么 surgical_approach 会吃血管侵犯的效应？因果路径分析**：

```
血管侵犯 → 病例复杂度 → 术者选择开腹 vs 微创 → surgical_approach
                     ↘                                 ↓
                        预后/OS  ←─────────────────────┘
```

`surgical_approach` 实际承载三类信息：
- 技术选择（真"入路"含义）
- 病例复杂度（简单的进微创通道，复杂血管侵犯几乎都开腹）
- 术者偏好 / 选择偏倚

它**部分位于暴露 → 结局的因果路径上**——把它放进模型相当于校正了主暴露的下游路径，会人为压低主暴露的独立效应。

**判别"混杂 vs 中介"的实操问题**：
- 这个变量在时间上发生在主暴露之前还是之后？→ surgical_approach 是术中决策，发生在血管侵犯被识别**之后** → 不是基线变量 → 不是理想混杂。
- 这个变量是否由主暴露部分决定？→ 是（VI 程度直接影响入路选择）→ 中介 / collider 嫌疑。
- 校正它后主暴露效应方向变化？→ 同向被压低（不是反转）→ 典型"过度校正"模式。

### 最终方案

**双模型策略**（不是删变量，是分层报告）：

- **Model 1（主模型）**：不含 `surgical_approach`。Definite VI HR 1.424 (1.08–1.88)，作为主结果。
- **Model 1b（敏感性分析）**：在 Model 1 基础上加 `surgical_approach`。Definite VI HR 1.283 (0.97–1.70)，方向一致但显著性减弱。

论文方法学段落写明：
> 手术入路与术中血管侵犯程度、病例筛选和手术复杂度密切相关，可能位于暴露与结局之间的部分因果路径上，因此未作为主模型的常规校正变量，而在敏感性分析中进一步纳入。

这样写**站得住**——不是"为了显著性删变量"，是"基于因果时序的方法学决策"。

### 通用原则 — 适用于

**通用诊断模式：去掉某协变量后主效应"突然显著"，怎么判断该不该删**

不是"显著就保留"，而是按这 4 问答：

1. **时序**：该协变量发生在主暴露之前还是之后？（之前 → 混杂；之后 → 中介嫌疑）
2. **因果方向**：该协变量是否由主暴露部分决定？（是 → 中介；否 → 可能是混杂）
3. **效应变化模式**：去掉后主暴露 HR 同向变大（典型中介 / 过度校正）vs 反向变（共线性 / Simpson 悖论嫌疑）
4. **领域知识**：这个变量在临床 / 业务上是不是"治疗决策的结果"而不是"基线特征"

如果答案指向"中介 / 选择"，就走主模型 + 敏感性分析的双跑结构。

**其他领域类比**：
- **经济学因果识别**：教育对收入的影响里要不要校正"职业类型"？职业是教育的结果——典型 bad control。
- **临床试验亚组分析**：随访期内某结果（如治疗依从性）作为协变量校正主治疗效应——这是中介，会压低 ITT 估计。
- **产品分析**：广告投放对留存的影响里要不要校正"打开次数"？打开次数本身被广告影响——bad control。

### SKILL 应用提示

**触发本案例的用户输出特征**：
- 用户连续贴两次 model summary，对比"加 X / 不加 X"
- 用户说"去掉 X 之后就显著了"、"加上 X 之后效果消失了"、"为什么差这么多"
- 主暴露效应方向不变但量级变化 ≥ 10%

**Claude 应做的事**：先夸用户跑了对比（这是好习惯），然后**警告不要为显著性删变量**；按 4 问诊断；如果指向中介 / 选择 → 主分析 + 敏感性分析双跑；写清楚方法学逻辑而不是结果导向；引用 SA-A 提示这是 5 因素诊断框架里"协变量吸走效应"那一条的实证。

## 案例 SA-C：完全分离的简化模型实战（Firth 不是唯一选择）

### 用户场景（原始）

用户跑围术期 logistic：cd3（Clavien-Dindo ≥ IIIa）和 infection_any 两个结局。原模型出现典型分离症状——`procedure_typeTP` 在 cd3 模型里 OR 极大 / CI 跨数量级；`preop_biliary_drainageYes` 在 infection 模型里同样炸掉。Claude 此前已警告"稀疏数据 + 分离"，用户主动要求："请给我'cd3 + infection 的简化 logistic 代码（避免分离问题版本）'"。

### 用户的初始反应 / 困惑

用户隐含问题是"既然分离了，不是该上 Firth 吗？"——把"分离 = Firth"当成自动反射。但这里的根因是**变量太多 / 类别太稀**，简化模型 + 用户能看懂结果 比 Firth 更优。

### 关键判断 / 诊断逻辑

**信号**：原模型里某个**特定分类水平**的 OR 极大或极小、CI 跨数量级、有 `fitted probabilities numerically 0 or 1 occurred` 警告。

**第一步：定位炸掉的水平，而不是整把换方法**
- cd3 里炸的是 `procedure_typeTP`（TP 即 total pancreatectomy，例数极少）
- infection 里炸的是 `preop_biliary_drainageYes`（在感染结局里事件分布极不平衡）

**第二步：根因分析——分离的来源是什么？**
- 来源 A：**结局事件数本身就少**（cd3 整体事件 < 30）→ Firth 是合适的工具
- 来源 B：**某个变量的低频类别在结局上 0/1 极不平衡**（TP 病例 < 10 且全无事件 / 全是事件）→ 简化变量编码（合并稀疏类）就能解决，不需要 Firth
- 来源 C：**变量太多**（十几个协变量 vs 30 个事件）→ 砍变量

**第三步：本案例对应的简化策略（不是 Firth）**
- `procedure_type` 三分类（PD / DP / TP，TP 极稀）→ 合并成二分类 `procedure_PD` (PD vs non-PD)
- `preop_biliary_drainage` 在感染模型里直接去掉
- 进一步简化版还可以再砍 `surgical_approach`（如果还不稳）

代码核心改动：
```r
new$procedure_PD <- ifelse(new$procedure_type == "PD", 1, 0)
new$procedure_PD <- factor(new$procedure_PD, levels = c(0, 1),
                           labels = c("Non-PD", "PD"))

mod_cd3_simple <- glm(
  cd3 ~ age + gender + bmi + diabetes +
    obstructive_jaundice + preop_biliary_drainage +
    procedure_PD + surgical_approach +
    Operation_duration + vascular_invasion,
  data = ana_cd3_simple, family = binomial()
)
```

**第四步：用户跑完，结果"稳定但阴性"**
简化模型里 cd3 的 Definite VI OR = 0.946 (0.314–2.532)；infection 的 Definite VI OR = 1.039 (0.368–2.689)。OR 和 CI 都回到了可解释范围，**但血管侵犯对这两个结局都没有独立信号**。

这是简化模型的典型结局：**模型稳定下来了，看到的是真实信号（或真实的"没信号"）**。不要因为"阴性"就再去试 Firth——Firth 救不了"事件数太少导致功效不足"的本质。

### 最终方案

**论文写法**：把围术期三个结局放一张总结表：
- cd2（事件数足够，主模型）：Definite VI OR 1.65 (0.97–2.81)，边缘趋势
- cd3（简化模型）：Definite VI OR 0.95 (0.31–2.53)，无独立相关
- infection（简化模型）：Definite VI OR 1.04 (0.37–2.69)，无独立相关

讨论里诚实写：血管侵犯增加的是"总体临床相关并发症负担"，不是最严重并发症或感染。

**方法学段落**：说明为什么 cd3 / infection 用简化模型（变量编码合并 + 稀疏变量删除），而不是直接报告原模型的炸 OR；如果还要再保险，作为补充材料附 Firth 回归结果（一致即可）。

### 通用原则 — 适用于

**通用诊断模式：logistic 分离症状的处理梯度**

| 症状 | 第一选择 | 第二选择 | 兜底 |
|---|---|---|---|
| 某个变量的低频类别炸 OR | 合并稀疏类（三分类 → 二分类） | 删该变量 | Firth |
| 整体事件数 < 10×变量数 | 砍变量 | 合并相关变量 | Firth |
| 事件数 < 30 + 变量数 5+ | Firth | 精确逻辑回归 | 改设计 |
| 完美预测（某变量 100% 决定结局） | 删变量 / 合并 | Firth | 报告"分类完美"事实 |

**核心原则**：先看分离的**来源是什么**，按来源选工具。Firth 不是万金油——它救"事件少 + 变量数合理"，救不了"事件少 + 变量超载"。

**简化模型的接受门槛**：用户能看懂；OR 和 CI 在常识范围内（OR 不超过 10，CI 不跨 3 个数量级）；主暴露的效应方向稳定。

**其他领域类比**：
- **HR 分析（人力资源）流失模型**：rare event（年流失率 5%）+ 多类别变量（部门 30 个），分离炸掉——优先合并部门到大类（技术 / 销售 / 运营），不要直接上 penalized logistic。
- **风控模型**：欺诈率 0.5% + 几十个特征，分离常见——先做特征筛选 / WoE 编码合并稀疏 bin，再考虑正则化。
- **罕见病研究**：暴露 - 罕见结局 logistic，事件数 < 20，多协变量——果断砍变量到 3-4 个核心，剩下用敏感性分析交叉验证。

### SKILL 应用提示

**触发本案例的用户输出特征**：
- 用户贴 logistic summary，某个或某几个 OR 极大（> 50）/ 极小（< 0.01）/ CI 跨多个数量级
- 用户在 R 里看到 `glm.fit: fitted probabilities numerically 0 or 1 occurred`
- 用户主动问"是不是要用 Firth"或"完全分离怎么办"
- 事件数 / 变量数比例 < 10

**Claude 应做的事**：
1. 先 `table(predictor, outcome)` 找出哪个变量哪个水平在搞鬼——**永远先定位再开方案**
2. 按"症状 → 处理梯度"表选第一手段；不要直接跳 Firth
3. 简化模型出结果后，明确告诉用户"稳定的阴性"和"分离造成的假阳"是两回事
4. 补充材料里报 Firth 作为 robustness check（不是替代）

## 案例 SA-D：加变量后主效应是否稳定（剂量观察 / 中介诊断）

### 用户场景（原始）

用户在 cd2（Clavien-Dindo ≥ II）logistic 主模型基础上加了 `Estimated_blood_loss`（术中估计出血量），贴出输出：

```
                                       OR        2.5 %     97.5 %
vascular_invasionBorderline / Contact  1.17552   0.66661   2.0409
vascular_invasionDefinite VI           1.68381   0.97912   2.8892
Estimated_blood_loss                   0.99989   0.99931   1.0004
```

加变量前 Definite VI OR = 1.6516 (0.97–2.81)；加之后 1.6838 (0.98–2.89)。出血量本身的 OR 几乎是 1，p 不显著。

### 用户的初始反应 / 困惑

两层困惑：
1. "出血量加进去主暴露几乎没动，是好事还是坏事？"
2. "出血量自己的 OR = 0.99989 接近 1，是不是没用？"

### 关键判断 / 诊断逻辑

**信号 1：主暴露效应"基本不变"是有意义的发现**

在中介诊断逻辑下：
- 如果出血量是血管侵犯影响 cd2 的**主要中介**，加进去主暴露 OR 应该明显下降（被中介吸收）
- 实际：1.65 → 1.68，几乎不变 → **出血量不是主要中介**
- 推论：血管侵犯影响 cd2 的机制更广义（解剖剥离困难、组织损伤、术后恢复慢、多种轻中度并发症累积），不只是"出血更多"

这个发现**对论文是加分**——证明主暴露效应不是被某个中间变量"伪造"出来的。

**信号 2：出血量 OR ≈ 1 不等于"没用"，是单位问题**

`Estimated_blood_loss` 单位是 1 ml，每增加 1 ml 风险变化当然非常小（OR 0.99989 ≈ 1）。换单位重跑：

```r
new$EBL_100 <- new$Estimated_blood_loss / 100
# 然后用 EBL_100 入模 → OR 会变成"每增加 100 ml 的相对风险"，可解释
```

**判别"中介 vs 混杂 vs 噪音"的诊断流程**：

| 加变量后主暴露效应 | 解释 | 处理 |
|---|---|---|
| 大幅下降（> 30%）+ 该变量自身显著 | 该变量是中介或强混杂 | 因果时序定中介 / 混杂；不放主模型，敏感性补一刀 |
| 小幅下降（10-30%）| 部分混杂或部分中介 | 主分析 + 敏感性，论文里讨论 |
| **几乎不变（< 10%）** | **该变量不是关键中介 / 混杂** | **加分项；写"主效应稳健"** |
| 反向上调 + 该变量自身反向 | 共线性 / Simpson 嫌疑 | 检查相关性 + VIF |

本案例属于第三种，最理想。

### 最终方案

**双模型策略 + 因果叙事**：

- 主模型（cd2）：不含出血量。Definite VI OR 1.65。
- 敏感性模型：加出血量。Definite VI OR 1.68。

论文写法：
> 在 CD≥II 的敏感性分析中，进一步将术中估计出血量纳入模型后，Definite VI 组发生临床相关并发症的风险估计值变化不大（OR 1.68，95% CI 0.98–2.89），提示术中血管侵犯程度与 CD≥II 之间的关联并不完全由术中出血量所解释。

讨论部分写：
> 由于术中出血量可能位于术中血管侵犯与围术期不良结局之间的部分因果路径中，本研究未将其作为主模型常规校正变量，而在敏感性分析中进一步纳入。结果显示，加入术中估计出血量后，明确血管侵犯与 CD≥II 之间的风险估计值基本稳定，提示该关联可能反映更广泛的手术复杂度和围术期负担，而非仅由出血增加所致。

### 通用原则 — 适用于

**通用诊断模式：剂量观察（dose-watching）= 加 / 减某变量看主暴露效应漂移**

这是因果推断里最便宜也最常用的稳健性检查。每加一个有嫌疑的变量，记录主暴露 OR/HR 的相对变化（百分比）：

- < 10%：稳健，可以写"effect not driven by X"
- 10-30%：部分中介 / 部分混杂，主分析 + 敏感性
- \> 30%：该变量主导，需深入因果建模

**与 SA-B 的对照**：
- SA-B：去掉 `surgical_approach` → 主暴露 HR 1.28 → 1.42（上调 11%）→ 该变量在压主效应（中介嫌疑）
- SA-D：加 `Estimated_blood_loss` → 主暴露 OR 1.65 → 1.68（变化 < 2%）→ 该变量不在效应链上

两个案例**用的是同一种方法（compare nested models）**，结论方向相反——这就是诊断的价值。

**单位问题（OR ≈ 1）**：连续变量的 OR/HR 永远要看单位是否合理。每 1 ml、每 1 天、每 1 元的 OR 必然接近 1。改成每 100 ml、每年、每 1000 元才有可解释性。

**其他领域类比**：
- **教育研究**：班级规模对成绩的影响，加入"作业时长"后效应基本不变 → 班级规模影响不是通过作业时长走的，可能是注意力 / 师生互动密度等更广义的机制。
- **健康行为研究**：运动对血压的影响，加入"BMI 变化"后效应稳定 → 运动效应不只是"减重→降压"，还有直接血管效应。
- **营销实验**：广告对销量的影响，加入"网站访问量"后效应稳定 → 广告机制不只通过流量增加（可能也通过品牌记忆等）。

## 附：4 个案例的方法学共同点

1. **永远先翻译"显著 / 不显著"成"方向 + 量级 + 不确定度"**——p 值是辅助，不是结论。
2. **嵌套模型对比是诊断的主力工具**——SA-A → SA-B → SA-D 都是。
3. **"为显著性而删变量"是论文方法学红线**——必须用因果时序 / 业务逻辑站住脚。
4. **简化 < Firth < 改设计**——分离问题按根因选工具，不要倒过来。
5. **不显著结果 ≠ 失败**——稳定的阴性、边缘趋势、效应稳健都是可写的发现。
