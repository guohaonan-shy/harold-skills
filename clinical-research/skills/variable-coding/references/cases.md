# variable-coding — 真实案例参考

本文件收录 4 个真实研究咨询案例，原始背景是胰腺外科血管侵犯研究的变量编码决策。每个案例附"通用原则"段落映射到其他领域。

**SKILL 主体讲泛化原则；本文件用于"遇到具体边缘编码情境时找类比"。**

## 案例 VC-A：三层结构如何从原始字段构建（迭代式定义）

### 用户场景（原始）

回顾性队列：胰腺癌根治术 474 例（PD/DP/TP 混合术式），用户想把"大血管侵犯"作为核心暴露变量做生存与并发症分析。原始数据是从手术记录里整理出的两列自由文本：

- **术中侵犯证据**：手术记录里出现"紧密粘连/包绕/受侵/无法分离"等关键词时记录的对应血管名（PV/SMV/SMA/CA/CHA/SA/SV/GDA/Henle 干/副肝右动脉等）
- **切除血管种类**：手术记录明确写了"切除"的血管名

### 用户的初始想法

第一轮提问时用户的认知混在一起：

- 想用"是否进行了血管切除重建"作为"是否发生侵犯"的代理
- 担心 SA/SV 这类"侵犯了但术式里本来就要切"的病例归类
- 不确定"血管鞘剥除"算不算血管侵犯证据

### 关键判断 / 推理过程（迭代演化骨架）

**第 1 轮 — AI 提出基本原则**：先把三个层面拆开，**不要混为一谈**：

1. 术中怀疑/提示血管侵犯（手术记录措辞）
2. 术中证实达到"无法安全分离，必须连同切除"的实际侵犯
3. 是否实施了血管切除重建技术（这是技术变量，不是肿瘤生物学变量）

→ **技术性出现 ≠ 病理意义**：DP 中常规切除 SA/SV、PD 中常规离断 GDA，都不能因为"切了"就当作侵犯证据。

**第 2 轮 — 用户挑战边缘案例**："那 DP 里 SA/SV 紧密粘连并切除的人群，到底算不算和切 PV/SMV/CA 一样的'明确侵犯'？"

→ AI 给出"判定特异性"框架：PV/SMV/SMA/CA/CHA 主干切除特异性高（不是常规步骤），SA/SV 在 DP/RAMPS 背景下特异性低（可能是术式常规处理）。所以两者不该并入同一层。SA/SV 切除 → **降级为交界态**。

**第 3 轮 — 用户进一步追问**："核心血管 PV/SMV 等紧密但可游离（未切）、以及 SMA/CA/CHA 鞘剥除——这两种情况怎么分？"

→ AI 在交界态内部再分亚型：
- **亚型 1（SA/SV 型）**：DP 背景下 SA/SV 紧密粘连并切除 — 非核心血管受累
- **亚型 2（核心血管粘连可游离型）**：PV/SMV/SMA/CA/CHA 紧密粘连但最终游离、未切 — 核心血管可疑受累
- **亚型 3（鞘剥除型）**：SMA/CA/CHA 鞘剥除 — 围血管组织受累

证据强度排序：亚型 2 > 亚型 1 > 亚型 3。

**第 4 轮 — 用户又问**："那手术记录写了 GDA/PDA/Henle 干/副肝右动脉/胃左静脉'受侵、与肿瘤无法分离'呢？这些算侵犯吗？"

→ AI 守住了边界：**即使写了"受侵"也不算研究终点意义上的"血管侵犯"**。理由：这些血管在相应术式中往往属于常规切断或处理对象，对肿瘤可切除性判断及核心血管侵犯分层的指示意义有限。**它们留在"未侵犯组"**，但可以增加备注变量"分支/常规处理血管受累描述"。

### 最终决定与配套做法

**主分层变量（三层）**：

| 层 | 名称 | 判定 |
|---|---|---|
| 0 | 无术中血管侵犯证据 | 无核心血管受累描述 + 未行核心大血管本体切除/重建；分支/属支/变异血管即使写"受侵"也归此层 |
| 1 | 交界态术中血管侵犯证据 | DP/RAMPS 下 SA/SV 切除 / 核心血管紧密但可游离未切 / 仅鞘剥除 |
| 2 | 明确核心大血管侵犯 | PV/SMV/SMA 主干/CA/CHA 主干被术中明确描述侵犯/包绕/无法分离，或实施了本体切除/重建 |

**配套做法**：
- 同时构建"交界态亚型变量"（SA/SV 型 / 核心粘连可游离型 / 鞘剥除型），保留临床异质性，主分析合并、亚型用于描述与敏感性
- 方法学段落里**显式定义"核心大血管"**包括哪几条（PV/SMV/SMA 主干/CA/CHA-HA 主干），不让范围漂移
- 多种证据共存时按强度归最高层：明确 > 交界态 > 无

### 通用原则 — 适用于

任何时候用**自由文本字段 + 多列原始记录**来构建有序分类变量，遇到"广义概念 vs 严格定义"的边界争议时：

1. **三层骨架先行**：强证据层 / 交界态层 / 无证据层。粒度细化在第二步。
2. **技术性出现 ≠ 病理意义**：同一原始值在不同上下文（术式/科室/疾病阶段）下临床含义不同，不能脱离上下文机械判定。**降级到交界态让用户决断**，不要替用户拍板。
3. **特异性差的证据降级，不是排除**。
4. **主定义讲严格、备注变量讲广义**——既不浪费信息，也不污染主终点。
5. **迭代式收敛**：第一轮给原则，让用户挑边缘案例 → 第二、三轮微调亚型与边界 → 最终落定方法学段落。**不要试图一次性给完美方案**。

**其他领域映射**：

- **AKI 编码**：KDIGO 强证据（肌酐 ≥ 1.5×基线 / 尿量 < 0.5 mL/kg/h × 6h） vs 交界态（肌酐轻度波动 / 单次尿量低但补液后回升） vs 无；**已知非肾源性的肌酐升高（如肌肉损伤）应降级到交界态而非排除**。
- **共病/Charlson**：强证据（明确诊断 + 规律治疗） vs 交界态（既往史无规律治疗 / 仅一次异常实验室） vs 无。妊娠期糖尿病、白大褂高血压属典型交界态。
- **影像学描述**："明确占位伴恶性征象" vs "可疑结节，难以定性" vs "未见异常"——把"可疑"单列为交界态，不要强行二分。

### SKILL 应用提示

当 Claude 遇到以下情境时回看本案例：
- 用户给的原始字段是**自由文本**（手术记录/影像报告/病程记录）
- 用户问"X 算不算 Y"的边界争议（尤其同一原始值在不同上下文下含义不同）
- 用户已经收集了"多列证据"（如证据列 + 行为列），想知道怎么交叉判定
- 用户的初版定义把"广义"和"严格"混在一起

**核心提醒**：先拆三层骨架，再问用户哪些边缘案例需要专门讨论，再用 AskUserQuestion 让用户对每个交界态拍板。**不要在用户给出全部边缘案例之前就提交终稿。**

## 案例 VC-B：样本量 vs 编码粒度的权衡

### 用户场景（原始）

延续 VC-A：交界态层经过细化后内部分了 3 个亚型（SA/SV 型、核心血管粘连可游离型、鞘剥除型），用户准备进入主分析时算了一下：**3 个亚型加起来才 95 例**。

### 用户的初始想法

用户已经把概念定义得很清晰（三亚型互不重叠，每一类都有清楚的判定准则），开始纠结："这 95 例虽然内部有差异，但加起来不多，需要分这么细吗？"——隐含焦虑是：分细了样本量撑不起，但合并了又怕丢失临床异质性。

### 关键判断 / 推理过程

- **概念分清 ≠ 统计分细**。这是两件事，可以解耦。
- **主分析分细的代价**：
  - 95 例分 3 组 → 每组 20-30 例，事件数更少 → KM、Cox、logistic 都不稳
  - HR 方向可能对但 P 值都不显著、CI 极宽 → 审稿人质疑"分组过细，样本不足"
  - 多因素模型校正其他协变量后更容易过拟合
- **不分细的代价**：方法学段落看不出研究者对内部异质性的认识，被审稿人问"你这是不是一锅炖"答不上来。
- **解决方案：双轨**
  - **主变量**只保留三层（0/1/2），用于 KM、Cox、并发症 logistic
  - **亚型变量**单独建一个（borderline_subtype: 1/2/3），保留在数据库里，用于：
    - 描述性统计（表 1 报告各亚型例数）
    - 敏感性分析（如剔除最弱证据的鞘剥除型再跑一遍主分析）
    - 必要时回应审稿人

### 最终决定与配套做法

**双轨变量构造**：

```
vascular_invasion_main           # 主分析用
  0 = 无 / 1 = 交界态 / 2 = 明确侵犯

vascular_invasion_borderline_subtype   # 描述与敏感性用
  0 = 非交界态
  1 = SA/SV 型
  2 = 核心血管粘连可游离型
  3 = 鞘剥除型
```

**方法学段落自我说明**：
> 虽然交界态术中血管侵犯证据组内部包括非核心血管受累型、核心血管粘连可游离型及血管鞘剥除型等不同情形，但考虑到样本量有限，为保证统计稳健性，本研究在主分析中将其合并为统一的"交界态术中血管侵犯证据组"，同时保留亚型信息用于描述性分析及敏感性分析。

**敏感性分析（推荐做一个就够）**：去掉鞘剥除型（最弱证据）后再跑一次主分析，看主结论是否稳健。

**什么时候才升级为正式比较**（写进 cases.md 备查）：
- 三亚型每组都 ≥ 25 例**且**结局事件数足够
- 三亚型临床特征差异极明显（如某型几乎全是头部癌、另一型全是体尾）
- 文章重点本来就是"内部异质性"

### 通用原则 — 适用于

**任何"概念分得细但每组样本量薄"的有序分类变量**：

1. **概念分清和统计分组是两回事**。可以方法学段落说"我们识别了 3 个亚型"，但分析层面只用合并主变量。
2. **主分析守稳健，亚型留补充**。每多一个分类层级就多一个过拟合风险，特别是多因素模型里。
3. **保留信息但不污染主终点**：数据库里把亚型保存为单独变量，"主-辅"双轨而不是"二选一"。
4. **敏感性分析的目的是证明主结论稳健**，不是为了把不显著的结果改显著。

**判定阈值经验**（参考，非绝对）：每亚组 < 25 例或事件数 < 5 时，倾向合并到主类。

**其他领域映射**：

- **共病严重度分级**：Charlson 单项里把肝病分轻度/中重度，但样本里中重度只有 8 例 → 主分析合并为"有肝病/无"，敏感性分析保留两层。
- **TNM 细分期**：T3a vs T3b 在小样本里几乎跑不出差异 → 主分析用 T3 合并，亚型变量保留 a/b。
- **NYHA 心功能分级**：原始 4 级，但 IV 级病例稀少 → 主分析合并 III-IV，描述性表格里报 III 和 IV 各多少例。
- **种族/人种细分类**：原始 8 个亚类大部分都不到 5%，主分析合并为 "白人 / 黑人 / 其他"，备注变量保留全部 8 类供审稿人查询。

### SKILL 应用提示

当用户在 §2-Q5（目标编码粒度）选了 C（多分类带亚型），但样本量明显不够时，主动提醒并提议双轨方案：**主分析合并 + 亚型保留**。不要直接砍掉亚型——那会丢失临床信息；也不要听任用户分得过细——那会让分析跑不稳。

## 案例 VC-C：多源信息冲突时的金标准选择

### 用户场景（原始）

延续 VC-A/B：用户在确定"如何用现有数据判定血管侵犯"时，发现自己手头有**至少三个数据源会同时描述同一概念**：

1. **术式列**（procedure_type，如 ODP+S / OPD / DP-CAR）——隐含手术规模
2. **切除血管种类列**（如"PV,SMV" / "SA,SV" / "GDA"）——记录哪些血管被切
3. **术中侵犯证据列**（自由文本派生，如"PV 紧密粘连"、"SMV 鞘剥除"）

这三列对同一例病人有时会"互相印证"，有时会"各说各话"。例如：术式是 ODP+S（DP 加脾切），切除血管种类写"SA,SV"，术中证据写"未见明显血管受累"——三者拼起来该归哪层？

### 用户的初始想法

最朴素的方案：直接拿"切除血管种类"列做硬证据——只要写了切除某血管，就算该血管被侵犯。

### 关键判断 / 推理过程

- **任何单列都不能独立作为金标准**。原因：
  - **切除血管种类**会因术式不同有"假阳性"：DP 里 SA/SV 是常规处理，PD 里 GDA 是常规离断；脱离术式列单看切除列，会把"技术性切除"误判为"病理性侵犯"。
  - **术式列**信息粒度不够：知道是 DP 不能告诉你 SA/SV 是不是"因侵犯"切的。
  - **术中侵犯证据列（文本）**有"假阴性"：术者写法不统一，有人写"紧密粘连"、有人写"包绕"、有人没写但实际切了——文本可能漏。
- **金标准应该是"组合判定"**而非单列：
  - **术式 × 切除血管种类**：交叉表才能解锁单列含义。同样写"SA,SV 切除"，在 ODP 背景下是交界态，在 OPD（PD 不应常规处理脾血管）背景下要升级怀疑。
  - **加上术中侵犯证据文本**作为第三方印证：当切除列和文本一致时证据最硬；不一致时降级到交界态。
- **优先级（金标准来源）**应在方法学里写清：
  1. **术中所见 + 切除行为一致** → 主判定依据（最硬）
  2. 仅有术中所见描述、无切除行为 → 交界态
  3. 仅有切除行为、无术中所见描述 → 看术式背景：核心血管（PV/SMV/SMA/CA/CHA 主干）切除升级为明确侵犯；非核心血管（SA/SV/GDA/属支）切除按术式判定

### 最终决定与配套做法

**金标准定义（写入 methods）**：

> 术中血管侵犯的判定综合参考：（1）术者对肿瘤与邻近血管关系的描述（"侵犯/包绕/紧密粘连/无法分离/可游离"）；（2）是否实施血管鞘剥除、围血管组织剥离、血管部分或整段切除及重建；（3）切除血管的种类及其在相应术式中的常规处理属性。三者综合后按预设规则归层。

**配套规则**（写入附录判定表）：
- A 类血管（PV/SMV/SMA 主干/CA/CHA 主干）：切除即可判定为明确侵犯（无须文本佐证）
- B 类血管（SA/SV）：切除需要结合术式（DP 背景归交界态，PD 背景升级怀疑但仍归交界态）
- C 类血管（GDA/PDA/Henle/副肝右 A 等）：切除不能判定侵犯，文本写"受侵"也不入主定义

**特殊情况**：
- 三源不一致时（如切除列空、文本写"紧密粘连"）→ 归交界态
- 术后病理报告与术中所见冲突时 → 在该研究中以"**术中所见**"为主判定（因为研究核心是"术中血管侵犯"这一概念），病理可作为敏感性分析的金标准对照

### 通用原则 — 适用于

**任何变量在原始数据中有多个互补/竞争的来源时**：

1. **不要默认任意单列为金标准**。先列所有可获得的来源，分析每个来源的偏倚方向（假阳/假阴）。
2. **明确"主判定来源"+ "辅证来源"**，并在方法学里写清优先级。
3. **三源一致 → 强证据；不一致 → 降级到交界态**，不要靠规则强行融合冲突。
4. **金标准应贴合研究问题本身**：研究的是"术中血管侵犯"就用术中所见为主；研究的是"病理学血管侵犯"就用病理报告为主——同一份数据集里不同研究问题的金标准可以不同。
5. **写进 methods**：审稿人最常问的就是"你为什么用这个变量来判定这个概念"，提前写清规则可以挡掉大量质疑。

**其他领域映射**：

- **糖尿病诊断**：HbA1c / FPG / OGTT / 临床诊断书写——每个来源都有偏倚（HbA1c 受贫血影响、FPG 受当日状态影响、临床诊断有医生主观）。研究中应明确主判定来源（如"以 HbA1c ≥ 6.5% 或既往明确诊断且规律治疗为主"），其他作敏感性。
- **肿瘤分期**：临床分期（cTNM）vs 病理分期（pTNM）vs 影像分期。研究终点不同选不同金标准——预测术前决策用 cTNM，研究术后预后用 pTNM。
- **AKI**：肌酐基线 vs 尿量标准 vs 临床诊断。两套标准可能冲突（肌酐升高但尿量正常），方法学里要交代取哪个或两者均满足。
- **认知障碍**：MMSE vs MoCA vs 临床诊断书写。用作筛查时取量表，用作硬终点时要求量表 + 临床诊断双满足。

### SKILL 应用提示

当 Claude 发现以下情境时回看本案例：
- 用户提到"我有 X 列、Y 列、Z 列都描述这个变量"
- 用户问"应该用哪个数据来判定 X"
- 编码出来后核查阶段发现某些病例三个来源互相矛盾

**核心提醒**：在编码规则里**显式列出"金标准来源 + 优先级"**（§5.1 模板里有这一行，要让用户填实）。三源不一致时归交界态，不要替用户编写融合规则。

## 案例 VC-D：国际分级标准的临床显著性阈值

### 用户场景（原始）

同一研究的并发症章节：用户要分析胰腺手术三大特殊并发症 POPF（术后胰瘘）、PPH（术后出血）、DGE（胃排空延迟），都有 ISGPS 国际共识分级（A/B/C 三级）。474 例样本，并发症作为次要结局。

### 用户的初始想法

最直观的做法：直接按 ISGPS 原版三级编码。但用户读完分级规则后意识到一个问题——**A 级在 POPF 里其实已经被 2016 版 ISGPS 改名为"biochemical leak"（生化漏），不再算真正的 POPF**。那 PPH 和 DGE 的 A 级呢？是不是也应该剔除？

### 关键判断 / 推理过程

- **不是所有等级都临床显著**。三大特殊并发症的最低等级（A 级或生化漏）特点是：
  - 实验室或影像偏离正常，但**没有改变临床处置**
  - 不需要特殊干预、不延长住院、不影响出院
  - 临床意义近似"亚临床异常"
- **研究终点应该贴合临床显著性**：
  - POPF 2016 版：A 级 → biochemical leak，**已被官方剔出 POPF 主定义**，研究里只统计 B/C
  - PPH（ISGPS 2007）：A 级是轻度早期出血，临床影响小
  - DGE（ISGPS 2007）：A 级是短暂胃排空慢，对治疗进程影响有限
- **结论**：三个并发症都**只取 B/C 级作为分析对象**，最低等级不计入主要结局。
- **追加问题：B/C 级 ↔ Clavien-Dindo（CD）的对应**？
  - ISGPS 专病分级看的是"该并发症本身的严重程度"
  - CD 看的是"所需治疗强度"（药物 / 输血 / 介入 / 全麻手术 / ICU / 死亡）
  - **两者不存在严格一一对应**，只能给参考范围：
    - POPF B → CD II–IIIa；POPF C → CD IIIb–V（多数 CD IV）
    - PPH B → CD II–III；PPH C → CD III–V
    - DGE B → 多数 CD II；DGE C → CD II–III，重症合并时 CD IV
  - **方法学里应说明**两套分级评价维度不同，不强行换算，分别报告。

### 最终决定与配套做法

**编码规则**：

| 并发症 | 标准 | 纳入研究 | 不纳入 |
|---|---|---|---|
| POPF | ISGPS 2016 | Grade B / Grade C | Biochemical leak（原 A 级） |
| PPH | ISGPS 2007 | Grade B / Grade C | Grade A |
| DGE | ISGPS 2007 | Grade B / Grade C | Grade A |

**方法学段落（可直接进论文）**：
> 考虑到术后特殊并发症的最低分级多提示生化学异常或轻度、短暂的术后恢复偏离，通常不需要显著干预，临床相关性有限。为提高研究终点的临床解释性并减少轻微事件对结果的稀释，本研究将具有明确临床意义的中重度并发症作为分析对象。具体定义为：POPF 按 2016 年 ISGPS 标准，仅纳入临床相关胰瘘（Grade B/C）；PPH 和 DGE 按 ISGPS 共识标准，仅纳入 Grade B/C 病例；各并发症最低等级事件不计入主要分析。

**CD 对应说明（如需要）**：
> POPF、PPH 及 DGE 的专病分级与 Clavien–Dindo 分级评价维度不同，前者反映特定并发症的严重程度，后者主要依据临床干预强度和器官功能影响进行分级，因此二者不存在严格一一对应关系。总体而言，Grade B 并发症多对应 CD II–III 级，Grade C 多对应 CD III–V 级。本研究分别按专病分级报告各并发症发生率，并按 CD 分级汇总总体严重并发症（CD ≥ III）作为补充结局。

**配套做法**：
- 描述性表格里仍可报告 A 级例数，但放在脚注或附表
- 如做总体严重并发症复合终点，定义为"CD ≥ III"或"任一 ISGPS B/C 级并发症"

### 通用原则 — 适用于

**任何使用国际分级标准（多级有序）的临床变量编码**：

1. **不要默认所有等级都临床显著**。每个分级标准的最低等级往往是"亚临床/生化漏"——读标准的最新共识看官方对最低等级的态度。
2. **研究终点要贴合"临床有意义阈值"**：把分级二分为"临床相关 / 亚临床"。常见阈值：
   - POPF / PPH / DGE → B/C
   - Clavien-Dindo → ≥ III（需介入/手术）或 ≥ II（需药物治疗）按研究问题选
   - AKI（KDIGO）→ Stage 2-3（避免 Stage 1 的不稳定性）
   - 出血（BARC）→ ≥ Type 2
3. **方法学里显式说明剔除最低等级的理由**——审稿人不会自动接受"我没分析 A 级"。
4. **跨标准换算**（如 ISGPS B/C ↔ CD）**给参考范围而非硬映射**。两套标准评价维度不同时，分别报告 + 一段说明，比强行换算稳得多。
5. **复合终点的优势**：当各专病分级的 B/C 级都不多时，可定义"任一 B/C 并发症"作为复合次要结局提升事件数。

**其他领域映射**：

- **AKI（KDIGO）**：Stage 1 包括"肌酐 ≥ 1.5×基线"——很多研究里这一阈值假阳性高（受补液、肌肉损伤影响），主分析常取 Stage 2-3，敏感性才纳入 Stage 1。
- **NYHA 心功能**：I 级是"无症状"，临床研究里常合并 I-II vs III-IV，不三分类。
- **ECOG**：0-1 vs ≥2 是常见分界（≥2 临床显著影响）。
- **GCS（Glasgow 昏迷评分）**：13-15 / 9-12 / ≤8——重度脑损伤通常以 ≤8 为分析终点。
- **BARC 出血分级**：Type 1（轻微出血）一般不计入主要安全终点，Type 2 起算。
- **CTCAE 不良事件分级**：Grade 1（轻度）多不进主要安全终点，Grade ≥ 3 是常用阈值。

### SKILL 应用提示

当用户提到任何带分级的国际共识标准（ISGPS / Clavien-Dindo / KDIGO / NYHA / ECOG / BARC / CTCAE 等）时，主动追问：

```
该标准下你打算把研究终点设在哪个阈值？常见做法：

  A) 全部等级（A/B/C 或 1/2/3 全用）—— 信息全，但最低等级常稀释效应
  B) 临床显著阈值起算（B/C 或 ≥ Stage 2 或 ≥ CD III）—— 主流做法
  C) 仅最重一级（C / Stage 3 / CD IV-V）—— 事件稀少时不推荐
  D) 自定义 —— 描述你的依据

你倾向哪个？
```

并提醒：选 B 时要在 methods 里写清剔除最低等级的理由。
