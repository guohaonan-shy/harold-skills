# 就事论事（factual）

## 适用

- 对方否定但**无具体依据**（模糊否定）
- olden-patterns §1 习惯性否定（标准命中）
- 对方在传递情绪多于传递事实
- 你想把讨论拉回可检验的层面
- **不知道选什么的默认策略** —— 冲突风险低 / 对各种对手稳定

## 不适用

- 对方确实在寻求情绪认可（少数；先看 olden-patterns 判断 §8 情绪绑架还是真受伤 → 后者切 reply-soft）
- 事实和规则都站在对方一侧——冷冰冰"对事实"反而显得逃避
- 对方决策权高 + 推卸（事实只能让你扛得更明白，不解决摘果型）→ reply-play-dumb
- 公开施压场合（事实回也可以但要先公开冷处理）→ reply-cold-public + 私下走 factual

## 应对剧本核心

**对方的杀伤力来自模糊** —— "我觉得不行" / "你这块不太到位"——没具体到能被反驳的事实。**就事论事 = 把模糊拆成可检验的具体子问题**，让讨论回到事实层。

**三步式**：

1. **事实定位**（1-2 句）—— 用名词、数据、文档 / 消息引用锚住讨论对象。避免 "你觉得" / "我感觉"——全部用可查证的表述
2. **拆开不清的点** —— 把对方的模糊否定 / 模糊施压拆成具体子问题，**编号列表** —— 结构感本身就降低情绪温度
3. **提议具体动作** —— 可执行的下一步（"我把 A 数据整理给你，你看完我们再同步 B"）。动作要带 **owner + 时间 + 输出物**

## 3 候选差异维度

reply-coach §7 生成时本策略的差异轴：

- **A. 保守版** —— 单点拆解 + 一个具体动作。最短最稳
- **B. 标准版** —— 全三段（事实 + 拆 2-3 个子问题 + 提议动作）。默认
- **C. 微刺版** —— 事实段引用对方原话直接锁住（"按你说的 X 看，事实是 Y" 句式），拆解时显式标"目前数据 / 文档不支持这个判断"，对抗感更强但仍冷静

## 缺什么必须先 AskUserQuestion 问

按 conventions.md §4，缺关键 concrete 信息**先问**：

- **可查证的事实** —— 不能编。问用户："对方那条里他模糊否定的具体是什么？你这边有什么可查的事实 / 数据 / 文档？"
- **拆解的子问题** —— 哪些点是真要拆的？问用户："你想让对方说清的具体是 1.X，2.Y 还是 3.Z？"
- **动作的 owner + deadline** —— "我们对一下"是模糊的。问用户："你想推的具体动作是什么？谁负责？什么时候出输出物？"

## 措辞要领

- 用**名词**代替**代词**（少用 "这个" / "那个"——指向不明给对方空间继续模糊）
- 避免情绪词（"感觉" / "担心" / "怕"）
- 避免反问（反问带情绪）
- 引用原话用直接引号，不要转述（转述易被说"你没理解我的意思"）
- 时态：过去 / 完成式描述事实，现在时描述待办

## 常见陷阱

- **变成辩论**：对方每点都回 → 进入对方节奏。原则：**只回核心**，非核心明确不接
- **堆数据 overwhelm**：两三个关键事实足够——多了对方没耐心读 / 或挑边缘点反攻
- **假中立实际阴阳**：冷静 ≠ 讽刺。"按您的方案…" 这种句式是在开战不是在论事
- **抽象到对方接不住**：用对方熟悉的术语、具体可查的文档
- **拒绝事实化反而升级到情绪话术** → 切 reply-defuse-emotion

## 和 Memory 的配合

- 档案 `[profile]` 标"看重数据 / 直接 / 不接情绪铺垫" → 开头就放关键数字
- `[strategy | outcome:✓ | scenario:相似]` 记录"哪次引用了什么证据奏效" → 复用同类证据
- 多次用 factual 都有效的人，`[profile]` 升格为"此人默认 factual 即可"
- user-profile `[profile]` 标"默认就事论事" → 这是用户偏好，没特判时强加权本策略

## 分支预判 hint（reply-coach §9 用）

- **分支 1（高概率）**：对方接住事实层 → 给具体回应或承认 → 按你提议的动作走，正常推进
- **分支 2（中概率）**：对方继续模糊 / 跳话题 → 你的下一句重复事实问句**不增减字**，就像 reply-anchor-time 的重复锚定句一样—模糊就再问一次
- **分支 3（低概率）**：对方升级到情绪话术 / ego 攻击 → 切 reply-defuse-emotion 或 reply-soft（看是绑架还是真 ego）
- **超过 2 步事实化无效**：脱离 reply-coach scope。档案标 `[strategy outcome:✗]`，下次切其他策略
