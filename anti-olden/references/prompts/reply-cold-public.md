# 公开冷处理 + 私下定界（cold-public）

## 适用

- 对方在**公开群 / @ 全体 / 跨部门场合**施压你
- olden-patterns §7 公开施压：用群里围观压你接受其要求
- 对方在私下 DM 里要么客气要么沉默，但群里就翻脸

## 不适用

- 对方就是**单纯找你 1v1**没在公开场合 → 用就事论事或柔和推进
- 私下 DM 同样施压（不是"公开"那个特征）→ 用强势推回 / 装傻 / 锚定时间窗
- 公开场合是真的有合作议题需要群里同步 → 别冷处理，正常对就行

## 应对剧本核心

**公开场合**和**私下场合**两套姿态，**严格分开**。

**群里只回事实 + 留尾巴**：
- 不接情绪 / 不解释 / 不辩论 / 不公开认错
- 用最短的事实回复 + "我们对一下" 句式
- 留尾巴指"把话锁死在私下" —— 把公开施压的能量切断

**私下 DM 划清责任边界**：
- 私下 DM 直接说边界："今天群里那条我不在公开场合接，原因是…"
- 把对方提的诉求拆成具体责任 + 数据 + 时间——是他的就归他，是你的就承认
- 必要时把这次"公开施压"留个 paper trail（档案里记 `[event | severity:medium | source:消息]` + 后续可作 strategy 复盘）

**核心精神**：剥夺对方"公开围观+你必须接"的能量。让公开场合变成"你只回事实"的低能量场，把真正的对话搬到私下——私下他没有围观加持就会回归正常人。

## 3 候选差异维度

- **A. 保守版（群里）** —— "这个咱们对一下"（一句，转私下）
- **B. 标准版（群里）** —— "这条具体情况我私下同步你 / 我们 1v1 对" + 一句最关键事实
- **C. 微刺版（群里）** —— "这条具体情况私下同步" + 引用对方原话表面认同实际锁死（"按你说的 X 看，事实是 Y") —— 暴露事实 + 不在公开论战

私下 DM 走另一套话术（A/B/C 一致都是私下定界，差异在群里那条）。

## 缺什么必须先 AskUserQuestion 问

按 conventions.md §4，缺关键 concrete 信息先问：
- **群里这条公开施压的"实质诉求"是什么** —— 模糊施压（"你这块得加把劲") vs 具体施压（"3 天内交 X")？AI 模型容易把模糊和具体当一样的处理
- **私下 DM 是不是已有过往记录** —— 之前私下他是客气还是同样施压？决定 DM 那段措辞软硬
- **是否需要 paper trail / 留痕** —— 用户决策"这次记不记成 [event] / 写不写飞书私聊存档"

## 措辞要领

**群里那条：**
- 字数极短（< 10 字最佳，最多 1 行）
- 不用反问 / 不用感叹 / 不解释
- 用"对一下" / "私下同步"句式

**私下 DM 那条：**
- 第一句直接说边界（"今天群里那条我不在公开场合接"）
- 中段拆诉求 + 拆责任（用编号）
- 末尾留一个具体下一步（不留就显得只是发火）

## 常见陷阱

- **群里手痒解释**：解释多了对方就有了围观素材。一行打死
- **私下也跟着冷**：私下不是要继续冷战，是要正常对话定界
- **不留痕**：公开施压模式重复出现 3 次以上 → 必须留 [event] + 累积 [behavior pattern:§7]，否则下次找不到证据
- **跟对方"我们论战吧"**：群里冷处理不是论战准备，是关闭论战

## 和 Memory 的配合

- 档案 `[behavior | pattern:§7 | seen:N]` 高 → 默认本策略
- `[profile | source:消息]` 标对方"私下沉默 / 公开攻击" → 强信号本策略
- `[strategy | outcome:✓]` 之前公开冷处理过有效 → 复用

## 分支预判 hint（reply-coach §9 用）

- **分支 1（高概率）**：他在群里继续追加 → 你保持冷（不接），最多回一句"私下同步" → 等他切私下 / 或他自己泄气
- **分支 2（中概率）**：他切私下 DM → 你按"私下定界"那段走，把责任 / 边界 / 数据说清
- **分支 3（低概率）**：他不切私下，反而升级公开 → 升级 olden-patterns §3 公开施压 → 切强势推回（公开但更硬）+ 同步上级
- **超过 2 步**：脱离 reply-coach，走真实策略（拉 leader / 走 HR / 留全部 paper trail）
