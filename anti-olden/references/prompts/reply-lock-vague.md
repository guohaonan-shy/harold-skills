# 模糊承诺反向锁死（lock-vague）

## 适用

- 对方用模糊话术施压你接受范围 / 责任 / 期望，但**不给具体动作 / 时间 / 责任人**
- olden-patterns §5 模糊施压："你这块得加把劲" / "我们要重视这个事" / "希望你能更主动"
- 对方在群里 / 邮件里发"建议" / "关心" / "提醒"，看似无害但暗藏要求
- 对方期望你"心领神会"自己接 → 出问题时撇清"我没说要这样"

## 不适用

- 对方明确说"你做 X，3 天内交" → 这是直接施压，不是模糊施压，用就事论事或强势推回
- 对方真的就是同事关心 → 别曲解，正常回应就行
- 对方有 ownership 了在指导你 → 那是 leadership 不是模糊施压，正常对话

## 应对剧本核心

模糊施压的杀伤力来自**对方留了"我没明确说要 X"的退路**——你做了，他坐享其成；你没做，他说"我提醒过你了"。

**反向锁死** = 把对方的模糊话术翻译成**具体动作 + 具体时间 + 具体责任人**，**让他确认**。两种结果都对你有利：

1. **他确认了** → 模糊变成具体，留下 paper trail，他不能再说"我没这么说"
2. **他回避确认 / 含糊其辞** → 你记录"经追问无具体结论"，下次同样模糊施压**不再接** —— 用户档案里写一条 `[strategy | outcome:✓ | scenario:模糊施压追问]`

**核心句式**：

> "想确认一下你说的 [对方原话 X] 具体指的是：
> 1. [动作 A]，截止 [时间]，由 [人] 负责
> 2. [动作 B]，截止 [时间]，由 [人] 负责
> 你的意思是 1 还是 2 还是别的？"

把对方的"建议 / 关心"翻译成 **2-3 个具体的可选项**，让他在选项里挑——挑了就锁死，不挑就暴露这是空压力。

## 3 候选差异维度

- **A. 保守版** —— 翻译为 1 个最常见可选项，温和确认："想跟你确认下，你说的 X 是希望我 [具体动作 + 时间 + 责任人]，对吗？"
- **B. 标准版** —— 翻译为 2-3 个选项让对方挑（如核心句式）
- **C. 微刺版** —— 翻译 + 显式留尾："想跟你确认下你说的 X 具体指什么；如果这次没明确我就按现有计划走，避免下次理解偏差"——把"不接模糊施压"作为默认行为说出来

## 缺什么必须先 AskUserQuestion 问

- **对方原话** —— 必须逐字贴，模糊施压的细节往往在用词里
- **当下你正在做的具体动作 / 计划** —— 翻译成"具体可选项"的素材来自你已有的工作上下文
- **paper trail 媒介** —— 群里 / DM / 邮件？决定锁死的格式（群里需要 @ 对方让他 reaction，DM 直接问）

## 措辞要领

- **不**说"你这话什么意思" —— 直接反问会显得对抗
- **不**直接接对方模糊话术（"好的我会加把劲" / "明白") —— 接了就锁死你自己
- **要做**：把对方的话**逐字引用**（"你说的 X" 用引号），然后翻译成具体选项
- 用编号 / 列表，让对方"勾选" —— 选项不勾就只能给具体说法，给不出就暴露

## 常见陷阱

- **过早 commit**：对方一说"加把劲"你就说"好的没问题" → 你已锁死自己，他保留模糊
- **猜对方意思过头**：你翻译的选项跟对方真实意图差很远，他说"这都不是我的意思" → 你显得理解能力差。**不要替对方解读太多**，3 个选项就够，留出"或者别的"逃逸通道
- **私下做了不留痕**：对方 DM 模糊施压 + 你私下解决了 + 出问题时他说"我没让你这样" → 必须 paper trail
- **追问太凶变成审讯**：用"想跟你确认 / 想理解你的具体期望" 这类温和词，不要"你到底要什么"

## 分支预判 hint（reply-coach §9 用）

- **分支 1（高概率）**：对方挑了你给的某个选项 → 模糊变具体，paper trail 留下 → 你按选项执行 → 出问题或交付时引用这次确认
- **分支 2（中概率）**：对方含糊回避（"看你方便 / 你看着办") → 你的下一句："那我先按 [你当前计划] 走，有具体调整麻烦明确告诉我" + 档案里记 `[strategy outcome:✓ | scenario:模糊施压追问]`
- **分支 3（低概率）**：对方升级（"你怎么连这个都不懂"）→ 切到 §8 情绪绑架 → 用策略 D 去情绪化 + 切回事实
- **超过 2 步**：对方持续模糊不肯具体化 → 这本身是清晰信号"对方不愿留 ownership" → 走真实策略（同步上级 / 留全部对话 paper trail）
