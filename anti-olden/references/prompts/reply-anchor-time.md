# 锚定时间窗 + 拒绝回到旧争议（anchor-time）

## 适用

- 对方反复翻旧账：把已经定论的旧议题当作新论据
- olden-patterns §6 反复翻旧账
- 用过去某次"模糊讨论"假装那是"已达成共识" → 实际只是没下结论
- 用 Q1 已经讨论过的细节来 derail Q2 当下的议题

## 不适用

- 对方真的指出**新发现**让旧结论需要修正 → 那不是翻旧账，是合理质疑，正常对话
- 你自己确实在旧议题上没说清楚 / 当时确实只是"模糊过去" → 那要重新结案，不能用本策略堵嘴

## 应对剧本核心

**锚定** = 用具体的日期 / 文档 / 决议截图把旧议题"封印" —— 不再是可争论的，是已结案的事实。

**拒绝回到** = 不重新论证那个结论 / 不解释为什么当时是那样定的 / 不接"那当时不应该这样" 的钩子。

**句式核心**：

> "这个我们 [时间] 在 [载体] 已经定了 [结论]。今天我们对的是 [当下议题] 。"

三件事缺一不可：
1. **时间锚** —— 具体日期 / 周次 / Q几（"上次"不行，对方会说"哪次"）
2. **载体锚** —— 文档链接 / 群消息 ID / 邮件 / 飞书消息 / 妙记纪要（口头说"我们达成共识"不算，对方会说"我没说我同意"）
3. **当下议题切换** —— 主动把话题切回今天要解决的，不停在"过去对不对"上

如果对方继续翻 → 重复同一句锚定，**不要新增解释 / 不要重新论证 / 不要让步说"好吧那这点你说得也有道理"**。重复同一句的目的是让对方意识到这条路走不通。

## 3 候选差异维度

- **A. 保守版** —— 仅锚定 + 切回，不评价对方的翻旧行为
- **B. 标准版** —— 锚定 + 切回 + 一句"如果你觉得旧结论有问题我们可以新建讨论，但今天议题是 X"
- **C. 微刺版** —— 锚定 + 切回 + 引用对方当时签字 / 接受的截图 / 文档链接 —— 让翻旧的成本明显上升

## 缺什么必须先 AskUserQuestion 问

- **具体的旧结论时间 + 载体** —— "上次" / "之前" 不行，问用户"是 X 月 Y 日的会议纪要还是 Z 文档？"
- **当下议题是什么** —— 锚定后要切回的话题，不能是 vague 的"那我们继续"
- **旧结论是否真有 paper trail** —— 如果当时只是口头模糊过去，本策略**不适用**（用户说"是的有"才用，否则提醒用户切策略）

## 措辞要领

- **不**说"你怎么又翻这个" —— 评价行为会让对方觉得是吵架不是论事
- **不**说"我们已经讨论过了" —— "我们已经讨论过"是模糊的，对方会说"那讨论过的结论是什么"
- **要说**："2026-Q1 立项文档第 3 节已写明 X" / "4-15 那场会议纪要第 5 条" —— 引用具体到能查
- 重复时**完全用同一句话**——不要换措辞，换措辞会让对方觉得你不确定

## 常见陷阱

- **重新论证**：对方说"那当时是因为 A 才这么定的，现在 B 变了" → 不接，再说一遍锚定句。如果 B 真的变了让他**单独提**新议题，不在当下讨论
- **过早让步**：对方坚持翻旧 3 轮 → 你心软说"好那我们看一下"——这等于本策略失效，对方学会了"翻 3 次能让你回去"，下次必翻 5 次
- **旧结论模糊**：你以为定了，实际只是当时没人反对 → 本策略不堪一击。用前必须确认 paper trail
- **公开锚定 + 私下让步**：群里堵了 + DM 私下"那我们再谈谈" → 等于公开做戏，对方学到了"公开堵后私下能让步"

## 和 Memory 的配合

## 分支预判 hint（reply-coach §9 用）

- **分支 1（高概率）**：对方第一次被锚 → 短暂沉默或转移话题 → 你接住转回当下议题，正常推进
- **分支 2（中概率）**：对方再翻一次（试探） → 你**完全重复**锚定句，不增减字 → 第 2 次基本就放弃
- **分支 3（低概率）**：对方第 3 次翻 + 加情绪化 → 升级到 §8 情绪绑架 → 切策略 D 去情绪化 + 切回事实
- **超过 3 步翻**：脱离 reply-coach，对方在系统性 derail 这个议题 → 走真实策略（找 leader / 议题升级 / 留 paper trail）
