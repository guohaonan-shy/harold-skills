# 评测模块

评测归 ai-eval 插件，这一段只把它接上：答「接」，用 Skill 工具调 `ai-eval:eval-setup`，照它的步骤在本会话里做完，再回到 setup 的「交回」。

- 它中途停下问人（读不到的列成「待确认」）：照它的问法在本会话里答。
- 它写的 `EVAL.md` 在**代码仓库根**，不进 home：setup 不替人提交，也不算进「代码仓库里没有新增的 idea-loop 文件」那条完成条件（它是 ai-eval 的文件）。

完成条件：`ai-eval:eval-setup` 走完了它自己的完成条件，或记下了停在哪。

## 交回

- `EVAL.md` 的路径（代码仓库根），写明要人在代码仓库里提交。
- `eval-setup` 留下的「待确认」项，原样列给人。
