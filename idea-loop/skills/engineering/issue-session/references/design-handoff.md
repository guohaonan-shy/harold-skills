# 碰 UI 的 spec：带人过设计

triage 会话里 spec 碰 UI（有「前端交互」小节）时读这份。完成条件：设计冻结的结果已提交到 home，人知道接下来是 `set todo`。

1. 要告诉人的现状、目标、要你定，就是 `idea-loop:to-spec` 第 5 步交 spec 的那段话，不复述；这里只补一句：「前端交互」里有哪几个要设计的场景。
2. 告诉人设计从 `/idea-loop:uiux-imagine` 开始（只能人调），停下等人。
3. 人设计完、`/idea-loop:uiux-refine` 把冻结结果提交到 home 之后，回会话的「triage 会话」第 3 步。
