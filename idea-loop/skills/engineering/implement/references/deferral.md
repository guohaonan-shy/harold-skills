# 延后：这一格这张证明不了

implementer 有一格验收这张工单证明不了（行为定了，要等后面那张的接口，或要人判断）时读这份。

延后写在那一格后面，框不勾：

```markdown
- [ ] <判据> ⏭ 延后 → 07：<为什么这张证明不了>
- [ ] <判据> ⏭ 延后 → PR 交付验收：<要人判断的是什么>
```

接手方只有两种：后面某张还没落地、能证明这一格的工单（在那张工单验收标准末尾追加 `- [ ] <判据>（继承自 NN）`，放进你的 commit）；或 PR 交付验收（要人判断）。写不出接手方就按停。标「人看」的格和延后给 PR 交付验收的格，素材照 `ui-tickets.md`「要人判断的部分，录成素材」做。
