# 人批示里的其他几种

`../SKILL.md` 的「处理条目」里那张动作表之外，人的批示还有这几种：

- **疑问**：直接回答。
- **接受实现、走设计变更**（UI 走查条目），或人自己改了主意：见 `../SKILL.md` 的「设计变更」。
- **批示带出上线前后的事**：要人在上线前做的，追加进 PR 描述 `rollback` 的「上线前要注意的」并写明为什么要人做；合并后 Claude 自己做的，追加进 `reference` 的清理清单（`dyna pr body set`，见 `idea-loop:pr` 的「PR 描述」）。
- **推翻**（对「已按规则处理」里某条）：原话记进同一条目的「你的批示」，按那张动作表的最后一列撤回。
- **要求改写汇报**：照 `idea-loop:pr` 的「Review 汇报」改写条目里的汇报部分，重贴，改了什么写进汇总。
