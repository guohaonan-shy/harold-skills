idea-loop 的流程只写**能力**（做什么），不写**用什么工具**。这个 skill 是能力清单：每个能力通用流程要它做什么、做不到时怎么退；具体怎么做，每个运行环境一份 reference。

## 怎么用

1. **认当前运行环境**：主会话开场有一行「当前运行环境：X」。没有这一行（子 agent 收不到）就自己跑 `node "${CLAUDE_PLUGIN_ROOT}/scripts/runtime-detect.mjs"`，环境变量随会话继承，打印的就是名字。
2. **读那份 reference 里这个能力的小节**：`references/<运行环境>.md`，小节名就是下表第一列。只读用到的那一节。
3. **照小节做**。小节写「没有」，或写的工具实际不在：走「退路」。

## 检测规则

打印哪个名字，按顺序第一条成立就停：

1. `IDEA_LOOP_RUNTIME` 有值：用它。值不在已知名单（`claude-desktop`、`magi`）里，脚本报错退出，不猜。
2. 有 `MAGI_SESSION_ID`：`magi`。
3. 否则 `claude-desktop`。

Claude 命令行、IDE 插件没有可靠的标记变量，落到 `claude-desktop`，缺的工具走退路。

## 能力清单

这张表是闭集：通用流程只引用这些名字；要新能力，先改这张表和每份 reference。reference 里每个能力一个 `##` 小节，名字与第一列一致。

| 能力 | 通用流程要它做什么 | 做不到时 |
|---|---|---|
| 定时任务 | 按时间开一个新会话跑一段 prompt；列出已有的；读上次成功运行的时间 | 退路 |
| 会话内循环 | 在当前会话里每隔一段时间再叫自己一次 | 退路 |
| 会话管理 | 列会话；开一个 issue 会话；给别的会话发消息；读一个会话的记录；会话收尾 | 调度：停下（例外一）；分组：跳过（例外二）；其余退路 |
| 浏览器 | 无头地开页面、量、截图、走用户路径；把一页摆给人看 | 退路；摆给人看另有退法，写在小节里 |
| 向人提问 | 给 2–4 个选项的单选题 | 改在对话里问 |
| 发布审阅页 | 发布一页 HTML 给人看，收回人的批示 | 退路；写成 HTML 文件，告诉人用浏览器打开 |
| 推送 | 人不在场时提醒一句 | 退路 |
| 发文件给人 | 把一张图或一个文件发到人看得到的地方 | 退路 |
| 调用 MCP | 调某个 MCP 服务器的工具（如 Linear） | 退路 |
| 装与设置 | 告诉人怎么接 MCP、装插件、加允许规则 | 退路 |

## 退路

当前运行环境对某个能力写了「没有」，或工具实际不在：

- 把要做的事原样交给人（prompt、命令、参数），在汇报里记「未做：运行环境 <名> 没有『<能力>』」。
- 例外一：调度（`idea-loop:issue-dispatch`）缺会话管理，停下说明，这一轮什么都不做。
- 例外二：会话管理里的「分组」缺了，跳过，不算未做。
- 向人提问缺了，改在对话里问（编号选项，等人回），不算未做。

退路只在这里写；各流程不再自带退路。

## 加一种运行环境

多写一份 `references/<名字>.md`，能力小节与上表一一对应；把名字加进 `scripts/runtime-detect.mjs` 的已知名单和检测规则。通用流程不动。
