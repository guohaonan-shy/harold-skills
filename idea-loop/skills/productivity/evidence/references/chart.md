# 图表

按要人判断的东西选 excalidrawer 的入口，用 Skill 工具调它：

| 要人判断的是什么 | 入口 |
|---|---|
| 谁跟谁、按什么顺序说话 | `excalidrawer:sequence` |
| 一个对象的状态怎么流转 | `excalidrawer:state-machine` |
| 分支判断，走哪条路 | `excalidrawer:flowchart` |
| 层级、从一个根往下拆 | `excalidrawer:tree` |
| 左右两种做法的差别 | `excalidrawer:comparison` |
| 数量对比、趋势、占比 | `excalidrawer:chart` |
| 分层的组件、谁依赖谁 | `excalidrawer:architecture` |

入口 skill 自己写怎么出图、怎么导出。

调不到入口 skill（技能列表里没有 `excalidrawer:*`）：停下，告诉人先装上 excalidrawer 插件（做法照 `dyna runtime show 装与设置`），装好再继续；你是子代理就在交回里写明缺它。
