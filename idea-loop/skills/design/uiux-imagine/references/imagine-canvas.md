# imagine 的画布

imagine 的画布是为了让人在几个真正不同的方向之间选：同一个问题出几个变种，摆在一块变种板上对比，每个变种只做到刚好分得出彼此。它跟 refine 的画布不是一种东西：refine 只有一个方向，求的是做对。

## 目录里有什么

位置见 wiki-conventions 的「目录」一节（`design/tmp/<spec-slug>/imagine/`），本地、不进 git：

```
imagine/
├── board.html            变种板：用 ?variant=<名字> 切变种，?state=<名字> 切状态
├── assets/               变种板引用的素材、抓来的组件与样式、生成的图
├── rounds.md             每轮记录：人的原话、点名留下的变种、交付原文；会话重开后从这里接着做
├── direction-note.md     方向说明，写法见 direction-note.md
└── handoff/              交接画布：选中的那一版导成的独立页面，refine 的第一版画布从它来
    ├── index.html
    └── assets/
```

## 变种板

人在内嵌浏览器里点它、看它动，所以它是一张能点、带真动效的页面，不是拼起来的截图。这一段比的常常是状态怎么变（能播 → 加载中 → 播放 / 失败），静帧看不出来。

- 一个文件 `board.html`，每轮刷新同一页，不另开。
- 变种竖着排，每个占满宽度。内嵌浏览器大约 800px 宽，三栏并排会把每个变种都挤变形。
- 每个变种在页面上标着：名字、赌的是什么一句、跟别的变种真实的差别在哪。
- 每个变种挂一段模拟时序，人点了能看到会发生什么（「加载 2 秒后播放」「1.3 秒后失败」「再点一次重试」），时序写在变种的标签上。
- 顶部一个「预览减弱动效」开关，切一个代替 `prefers-reduced-motion: reduce` 的 class。减弱动效时方向最容易露馅（转圈的图标一停就像卡死），这是方向层的反应，属于这一段。
- 保真度只做到分得出彼此。真动效不算加保真度：比状态变化时，不动就分不出变种。
- 语言高度不出页面，出风格样张：色板、字体标本、几个形状、一小段语气示例。

## 在线上 UI 上出变种

改动落在已上线的界面上时，每个变种都是线上真组件的克隆，只改这次要动的地方：

1. 在本地开发环境用 Playwright 打开真页面，把它带到对的状态（登录、造数据、拦请求），取目标组件的 `outerHTML`。设计档案里有这个页面，先用档案的「页面」查询看它有哪些状态、区域与组件，知道要抓哪几个。
2. 取整页 CSS：遍历 `document.styleSheets`，拼起每条规则的 `cssText`，把相对的 `url(/…)` 改成开发服务器的绝对地址，不然字体和图标加载不了。
3. Playwright MCP 的代码沙箱写不了文件。在 `imagine/` 里起一个允许跨域的小 HTTP 服务，收到 POST 就把内容写盘，在页面里 `fetch` 过去。
4. 拼 `board.html`：抓来的 CSS 放一次，每个变种一份克隆，只改要动的部分，各接各的模拟时序。

踩过的坑：

- 抓的时候组件要处在静止态。抓到加载中，它就成了每个变种对比的「基线」。克隆前先看一眼抓到的是什么。
- Playwright 代码沙箱里没有 `setTimeout`，等待用 `page.waitForTimeout(ms)`。
- 全新的界面没有可克隆的，从零做，用同一块板。

抓取用的开发服务器和接收服务，谁起的谁停。

## 交接画布

人选中的那一版不扔：收工时导成 `handoff/index.html`，refine 拿它当第一版画布，不再从方向说明的文字重建，也不再重抓线上组件。

- **去掉**变种板的外壳：顶栏、变种标签和「赌什么」、时序说明、`?variant=` 切换、别的变种。「预览减弱动效」开关换成真的 `prefers-reduced-motion` 媒体查询。
- **保留**让它成为那一版的东西：`?state=` 状态切换（状态名与方向说明「验收矩阵」里的一致，refine 的画布沿用同一套名字）、真动效和模拟时序、从线上克隆来的组件标记与 CSS。没动的部分保持线上原样，不重画。
- **自包含**：图、字体、抓来的 CSS 里每个 `url(…)` 都复制进 `handoff/assets/`，改成相对路径。不依赖 `board.html`、`imagine/assets/`、开发服务器、接收服务或绝对地址，任何静态服务器甚至 `file://` 都打得开。refine 会把它原样复制进画布目录，`assets/…` 在那里也要解析得到。
- **保真度跟选中的那一版一样**：不替 refine 加，也不删到「看起来更干净」。方向说明构成清单里的每一项在画布上都看得到。
- **部分冻结后重开**：`handoff/` 整个重写，只含重开的那几块，以冻结画布的现状为基线。
- 自检：对每个 `?state=` headless 截图，确认打得开、状态能切、没有 404 的素材、控制台没有报错，并和变种板上选中那一版的同一状态对一眼。

## 清理

收工时清掉：`board.html`、落选的变种、抓来的东西、风格样张、`imagine/assets/`、`rounds.md`，以及抓取用的服务。留下方向说明和 `handoff/`，它们是 refine 的输入。清完再打开一次 `handoff/index.html`，它不该依赖被清掉的东西。

refine 冻结时，整个 `imagine/` 连同交接画布一起清掉。
