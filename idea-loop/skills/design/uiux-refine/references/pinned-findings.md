# 人说保留之后

编排者问人「保留 / 改」、人说**保留**时读。人说**改**走「人的方向修订」，不读这里。

## 三件事，缺一不可

1. **方向说明**：在那一项下面追加一行缩进的子条目（构成清单的块照常过 `direction-note-check`，这一行不是构成项，不影响它）：
   `    - 人保留（<日期>）：评委曾提「<意见摘要>」，人说保留 <该项的原样>`
2. **ledger**（`canvas/work/ledger.md`）：一行，记人的原话和这条意见。画布不动，designer 不用参与。
3. **之后每一轮**：起评委时把方向说明里所有「人保留」的项交给它，告诉它这几处是人亲自定的、不算差距。评委仍然提到其中一项的，按那一行直接拦下，不交给 designer，人只问一次。停下摆给人时带一句「已按人保留拦下 N 条」。

这一轮的分数照评委给的算：它评的时候还不知道这一项人要保留。从下一轮起，交给评委的输入里就有它了。
