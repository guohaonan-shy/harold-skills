# 烤进整句标题的封面

清单、对比这类文章，最锋利的一句话本身就是封面时读这份。主体换成整句标题，不再画母题。

- 居中。列表卡片会居中裁掉两侧，居中的字经得住对称裁切，靠边的字被推到边上显得挤。
- 半粗（font-weight 600），不用特粗；行高约 1.3，字距接近正常。
- 四边都留白，不小于内框（离边 12%）。排成两行、总宽约占内框的六成；字体字重取 DESIGN.md `typography` 里标题档，没有就用模板的字体。
- 一个强调词可以用 75% 不透明度的白，一句里最多一处。
- 页面的横幅会把文章标题叠在封面上的，整句标题会和叠上去的标题重复：看 `R/crop-check.html` 里的叠加效果，重复就改回无字主体。
- 渲染照 [render.md](render.md)：标题写进模板的 `<h1 id="headline">`。
