# 默认配方

项目没配封面配方（`blog-cover`）时，`cover` 用这一份。某一项项目配了，以项目的为准。

## 底色与主色

暗色底加一团有机渐变的磨砂：底色 `--base`，主色 `--accent`，`R/cover-template.html` 用 `color-mix` 从这两个值算出渐变的其余几档。DESIGN.md 的 `colors` 有主色 token 的，`--accent` 取它，`--base` 取它混黑的暗色；没有就从下表按文章轮着取，相邻文章换一行：

| 色相 | `--base` | `--accent` |
|---|---|---|
| 靛蓝 | `#12141f` | `#4f5fd0` |
| 青绿 | `#0f1a1c` | `#2a9d9a` |
| 梅紫 | `#1a1220` | `#9a54b8` |
| 琥珀 | `#1c1710` | `#c98a2b` |

## 主体

一个母题，白色线稿或简单几何，描边不粗不细（1600 宽的画布上约 6px），平静克制，不做图标感，不做玻璃质感。母题要对应论点：

| 论点的形状 | 母题 |
|---|---|
| 多个输入收成一个结论 | 从四周汇向一点的线 |
| 几套标准共用一把尺子 | 相互重叠的圆 |
| 一步步递进 | 逐级升高的台阶或条 |
| 把一团东西拆开 | 一个圆被分成几段弧 |

自己写 SVG（模板里的 `<g id="motif">`），不借图标库。

## 提示词骨架（项目配了生图工具、没有配方时用）

> 16:9 的抽象图形，不是照片。一个清晰的母题：<主体>，用白色线稿或简单几何表达，描边粗细适中。平静克制，不要图标感，不要玻璃质感。背景是深色磨砂：<主色>色调的柔和渐变，带细腻颗粒。画面里没有文字、没有 logo、没有界面。
