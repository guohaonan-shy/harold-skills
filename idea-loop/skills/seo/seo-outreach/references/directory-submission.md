# 目录提交

目录或名录站点的提交表单。提交页网址由人给，或在 issue 证据里。需要『人的浏览器』。

1. 在新标签页打开提交页，不动人已有的标签页。表单信息取资产页面和 `SEO.md` 的「站点」（名称、网址、一句话描述、类别）；这些里没有的项留空，在推送里点名，不猜不编。
2. 遇到登录页、人机验证：停下，用『推送』说明哪一页卡在哪里，等人处理完说一声再继续。不注册账号、不输入密码。
3. 填好后停在提交按钮前，不点：截图经『发文件给人』发出，用『推送』提醒「目录提交页已填好等你点」，写明站点，页面留在人的浏览器里。
4. 人说「提交」：回到那一页，表单还是填好的样子才点提交，再截一张提交后的页面；页面关了或内容变了，重填、重新截图、再等人说「提交」。
5. 记录：同目录写 `<活动短名>-<站点短名>.md`（`type: record`，填了哪些字段和值），跟进表加一行：联系方式写提交页网址，角度写「目录提交」，草稿指向这份记录，草稿 id、线程 id 留空；填好等人点时状态「待发送」，点了之后「已发送」，更新于今天。
6. 记录和跟进表的改动照主文件「交付」第 2 步 `commit` 到 home。

没有『人的浏览器』：不填，照主文件「写草稿」的做法把要填的字段和值写进 `docs/` 的记录文件，用『推送』提醒「草稿在 <路径>」，人自己去填。

完成条件：表单停在提交按钮前、人收到推送；或人说「提交」后已点并截了图；记录和跟进表已落地。
