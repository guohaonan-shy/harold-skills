idea-loop 的流程只写**能力**（做什么），不写**用什么工具**。这份是能力清单：每个能力通用流程要它做什么、做不到时怎么退；具体怎么做，每个运行环境一份数据，用 `dyna runtime show <能力>` 取当前环境那一节。主会话开场已注入当前环境的全文，子 agent 收不到注入，自己取。怎么认环境、怎么加一种运行环境，见 `dyna runtime --help`。

## 能力清单

这张表是闭集：通用流程只引用这些名字；要新能力，先改这张表和每份数据。数据里每个能力一个 `##` 小节，名字与第一列一致。

| 能力 | 通用流程要它做什么 | 做不到时 |
|---|---|---|
| 定时任务 | 按时间开一个新会话跑一段 prompt；列出已有的；读上次成功运行的时间 | 退路 |
| 会话内循环 | 在当前会话里每隔一段时间再叫自己一次 | 退路 |
| 会话管理 | 列会话；开一个 issue 会话；进自己的 worktree；给别的会话发消息；读一个会话的记录；会话收尾 | 调度：停下（例外一）；分组：跳过（例外二）；其余退路 |
| 浏览器 | 无头地开页面、量、截图、走用户路径；把一页摆给人看 | 退路；摆给人看另有退法，写在小节里 |
| 人的浏览器 | 在人自己的浏览器里（带人的登录态）打开页面、填表、截图 | 退路 |
| 向人提问 | 给 2–4 个选项的单选题 | 改在对话里问 |
| 发布审阅页 | 发布一页 HTML 给人看，收回人的批示 | 退路；写成 HTML 文件，告诉人用浏览器打开 |
| 推送 | 人不在场时提醒一句 | 退路 |
| 发文件给人 | 把一张图或一个文件发到人看得到的地方 | 退路 |
| 调用 MCP | 调某个 MCP 服务器的工具（如 Linear） | 退路 |
| 装与设置 | 告诉人怎么接 MCP、装插件、加允许规则 | 退路 |

## 退路

当前运行环境对某个能力写了「没有」，或工具实际不在：

- 把要做的事原样交给人（prompt、命令、参数），在汇报里记「未做：运行环境 <名> 没有『<能力>』」。
- 例外一：调度（`idea-loop:issue-dispatch`）缺会话管理，停下说明，这一轮什么都不做。
- 例外二：会话管理里的「分组」缺了，跳过，不算未做。
- 向人提问缺了，改在对话里问（编号选项，等人回），不算未做。

退路只在这里写；各流程不再自带退路。

## 能力模板

写一份运行环境说明时用（`dyna runtime check` 照它核）；会话里用不到，开场注入不带这一节。每个能力一个 `###`，下面是工作流要它做的几项，一项一行，以加粗的项名开头，写三样：传入（要给它什么）、拿回（得到什么）、做不到时（怎么办）。

说明里每个能力那一节：模板列的每一项，都要有一个同名的加粗项名，后面写这个环境怎么做，或写「没有」（这一项做不到，走做不到时那一栏）；整个能力都做不到，那一节只写「没有」。说明里可以多写模板没有的项。

### 定时任务

- **列出**：传入：无；拿回：已有的任务（id、表达式、prompt）；做不到时：退路。
- **创建**：传入：任务 id、标题、cron 表达式（分钟避开 0 和 30）、工作目录、prompt；拿回：任务已建；做不到时：退路，把 prompt 和任务 id 交给人自己建。
- **更新**：传入：任务 id，要改的表达式、prompt 或启停；拿回：任务已改；做不到时：退路。
- **读上次成功运行的时间**：传入：任务 id；拿回：时间，读不到就是没有；做不到时：流程按没有基准处理。

### 会话内循环

- **设一个循环**：传入：间隔、每次回到本会话的文字；拿回：循环 id；做不到时：退路。
- **列出循环**：传入：无；拿回：本会话里的循环；做不到时：退路。
- **取消一个循环**：传入：循环 id；拿回：循环已取消；做不到时：退路。

### 会话管理

- **列会话**：传入：分组名（没有分组就不传）、条数上限；拿回：没归档的会话（id、标题、状态）；做不到时：调度整轮停下（例外一），其余走退路。
- **开一个 issue 会话**：传入：项目的 clone（会话开在这里，worktree 由会话自己建）、标题「<仓库名>#<号> <标题>」、分组名、issue 会话的 prompt；拿回：会话 id；做不到时：这个 issue 本轮不交出，写进汇报，下一轮再试；整项都没有，调度整轮停下（例外一）。
- **给别的会话发消息**：传入：会话 id、原文；拿回：消息已发出；做不到时：退路。
- **读一个会话的记录**：传入：会话 id（自己写 self）；拿回：记录文件；做不到时：退路。
- **进自己的 worktree**：传入：`dyna worktree add` 打印的路径；拿回：之后的命令和文件读写都在那个 worktree 里；做不到时：退路。
- **会话收尾**：传入：自己的会话 id、原因（「#<号> done」之类一句话）；拿回：会话已结束（worktree、分支、进程在这之前已由会话自己 `dyna worktree remove` 收掉，这一项不管它们）；做不到时：退路。
- **分组**：传入：分组名、要移的会话、标题「<仓库名>#<号> <标题>」；拿回：会话在对应的分组里，标题已改；做不到时：跳过（例外二），不算未做。
- **怎么一轮一轮跑**：传入：调度间隔（30 分钟）、起 `idea-loop:issue-dispatch` 的 prompt、工作目录（home）；拿回：每轮开出一个新的调度会话，和下次运行的时间；做不到时：调度整轮停下（例外一）。
- **怎么数开着的会话**：传入：`dyna home dispatch` 给的分组名、本项目的仓库名；拿回：triage、in-progress 各开着几个（issue 会话开出的子会话不占位，另记个数）；做不到时：调度整轮停下（例外一）。
- **怎么交出 issue**：传入：issue 号、仓库名、时段（`triage` 或 `todo`）、issue 会话的 prompt；拿回：一个开好、归了位、发了任务的 issue 会话，调度记录里记上一笔（早上汇总读它）；做不到时：这个 issue 本轮不交出，写进汇报，下一轮再试。

### 浏览器

- **无头操作**：传入：地址、视口、要走的步骤（点击、填写、截图、量值）；拿回：截图文件、量到的值、控制台信息；做不到时：退路。
- **执行任意 JS**：传入：要在页面里跑的代码；拿回：返回值（要存成文件的另给办法）；做不到时：退路，这一步交给人，记「未做」。
- **造慢网络、失败的请求**：传入：要拦的请求、延迟或要返回的状态；拿回：页面处在那个状态；做不到时：退路，这一格交给人。
- **把一页摆给人看**：传入：地址（本地文件先起静态服务器）；拿回：人面前打开着的那一页；做不到时：退路，截一张图经「发文件给人」发出，附上地址，并说明看不到动效和交互。
- **并行时抢锁**：传入：锁目录、owner 名；拿回：独占会话里的浏览器（每个 agent 各开窗口的环境不用锁）；做不到时：等了 30 分钟还没拿到，就停下，在交回里写明卡在锁上。
- **要麦克风的流程**：传入：要走的流程（录音、语音面试）；拿回：带麦克风走完的结果；做不到时：退路。

### 人的浏览器

- **开页面**：传入：地址；拿回：在新标签页里打开的页面，人已有的标签页不动；做不到时：退路。
- **读页面**：传入：无；拿回：页面上的文字或元素；做不到时：退路。
- **填表**：传入：字段和值；拿回：表已填，登录页、验证码、支付页停下交给人；做不到时：退路，把要填的内容和网址交给人。
- **截图**：传入：无；拿回：截图文件；做不到时：退路。

### 向人提问

- **问一个单选题**：传入：题目、2–4 个选项；拿回：人选的那一项；做不到时：改在对话里问（编号选项，等人回），不算未做。

### 发布审阅页

- **发布一页**：传入：一个 HTML 文件（或目录）；拿回：页面的地址；做不到时：退路，写成 HTML 文件，告诉人用浏览器打开。
- **收回人的批示**：传入：无；拿回：人在页面或会话里给的批示；做不到时：退路。

### 推送

- **推一句话**：传入：一句话，写明要人做什么；拿回：已推出；做不到时：退路。

### 发文件给人

- **发一个文件**：传入：一张图或一个文件的路径；拿回：人看得到的位置（链接或侧栏）；做不到时：退路。

### 调用 MCP

- **调一个 MCP 工具**：传入：服务器名、工具名、参数；拿回：工具的返回；做不到时：退路。

### 装与设置

- **MCP**：传入：服务器名、地址；拿回：告诉人怎么接、怎么查有没有；做不到时：退路。
- **Playwright MCP**：传入：无；拿回：告诉人无头浏览器在这个环境里怎么装、怎么查、怎么修（必需）；做不到时：退路。
- **Mobbin MCP**：传入：无；拿回：告诉人怎么接、怎么查有没有、怎么登录（可选，设计调研用）；做不到时：设计调研停下，只有它受影响。
- **允许规则**：传入：要人加的规则；拿回：规则打印给人，由人自己加，不替人改权限设置；做不到时：退路。
