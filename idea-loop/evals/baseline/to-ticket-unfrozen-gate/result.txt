**设计冻结闸门**：spec 是 `等设计冻结`、§4 没有冻结摘要小节，所以 04–07 一律落 `⛔ 未冻结 —— 不可开工`。我没有替它冻结，也没有编造画布指针、matrix 格子或 mismatch 数字——那几项是收敛设计那一段时自己填的。这四张票照切、照编号、照进依赖图，只是还不能开工；`implement` 会认 ⛔ 这个标记本身把它们拦下。

**UI 票的比对项**：按规矩，只有誊写了冻结摘要的票才在验收标准里写比对项。这四张没有摘要可誊，所以每张最后一条写的是「视觉比对项待冻结摘要补齐，未补齐前不算可开工」——把缺口标在验收标准里，而不是拿一条填不出数字的假比对项占位。

**存量回归**：这个仓库没有 `docs/testing/` 的 test-cases 库，也没有任何已落地的测试套件——如实写了「无 test-cases 库」，点名的是 spec §5 自己列的那几台仪器（TDD 单元 / TDD API / 真 DB / `qa:*` / UI 实现环测量脚本），按角色指名，没有编路径。
