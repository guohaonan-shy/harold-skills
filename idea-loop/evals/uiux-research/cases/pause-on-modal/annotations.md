# pause-on-modal

> 人看完这个 case 跑出来的那页 HTML，在下面记问题。每次跑记一段，不删旧的。
> 产物该包含什么，从这些标注里逐步收敛；这里不打分，不写「过 / 不过」。

**默认 prompt**：/idea-loop:uiux-research 练习中弹出确认弹窗时，倒计时和录音要不要暂停？别人怎么做？

**上次真实会话里这次调研实际帮了什么 / 没帮上什么**（来源：同 refine（弹窗出现时要不要暂停））：没帮上：这是时间 / 行为维度的问题，静态截图答不了。好的结果应该在「不能回答什么」里照实写出来，不硬凑参考。
