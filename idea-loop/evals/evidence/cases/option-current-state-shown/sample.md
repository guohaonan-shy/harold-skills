# 样本：选项提到「现在的做法」，当场摆出现在的样子

**一句话**：一道要人定的题，选项里写「现在的做法」，却只用一行字说它；人看不懂现在是什么样，没法比。好的做法是把现在的样子当场摆出来，再讲改成什么样。

## 出处

harold-skills#128 的 triage 会话（2026-11-13）。决定记录 `docs/raw/decisions/128.md`：题 2、候选 4。

## 当时产出的原文

要人定「整段钉住的滚动驱动段，进档案时存成什么形状」。摆给人的两个选项（取自决定记录，原会话记录没有留存，这里是决定记录里的转述）：

- 每一步一个段内状态、一张钉住视口图（**现在的做法**）
- 拼成一段一张图；推荐另开 issue 改成拼图

「现在的做法」只有这四个字，没说它在档案里长什么样。

## 人指出的问题

人原话：「现在的做法，比如 listen & repeat 那个滚动驱动是做成什么样的？」

没见过现在的样子，两个选项没法比；人要先问清现状才能选。人看到档案里的真实图之后，选了现在的拍法，并进当前 issue 做，没有另开。

## 好的长什么样

题里一提到「现在的做法」，就在同一处摆出现在的样子：

- 一张图或档案里的真实样子：现在一个三步的滚动驱动段在档案里是几个状态、每个状态一张什么图、第一步算入口状态还是单独一个段内状态；
- 再摆「拼成一张」做完之后的样子，两个并排；
- 图旁边一句话说它是谁、从哪来（哪个页面的档案、哪个文件），不留「就是现在这样」这类要人自己去找的指代。

不好的样子：选项只有「现在的做法」「拼成一张图」这类名字，要人自己去翻档案才知道指什么。

## 回放这一格怎么跑

- 现场：当时的提交 `d3a8607`，prompt 取人在会话里已定的前情，再让会话自己对着仓库查「档案现在怎么存这类段」并摆成题；
- 换过的地方：当时人看到的是目标项目设计档案里 listen & repeat 页面的真实图，那份档案不在本仓库里；回放里能取的真实材料是本仓库的设计档案说明、ADR 0005 和分段脚本的夹具，题里「现在的做法」要从这些里取；
- 大小：large（出图可能开浏览器或起绘图工具），由编排者在 PR 开出来后当场跑。
