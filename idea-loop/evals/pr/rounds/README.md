# #452 triage 的四轮样本产出

#452 triage 会话（2026-11-24 到 11-25）照 `pr/references/description.md` 草稿，让子代理把 5 个真实 PR 的描述各重写四轮：`description-v1.md` 到 `description-v3.md` 是前三轮，`description.md` 是第四轮（Harold 定的模板），`notes.md` 是每轮子代理记下的「标准没说清」与字数。每轮之间的改动和 Harold 的批示在 `docs/raw/decisions/452.md` 题 20–27。

这是实现 `idea-loop/evals/pr/` 五个标注样本的素材，样本建好后这个目录可以删。

描述里引用的图（png、excalidraw）没进 git（推送大文件时连接被重置），在 #331 共享笔记目录的 `452-pr-samples/` 下有完整一份；建样本时从那里取，或照描述里的说明重拍。
