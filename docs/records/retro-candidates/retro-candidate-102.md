# idea-loop decision-rules：PR 流程里能指出不丢东西的边缘情形，照规则接受成已知限制

- 信号：对题的选择（来自 #55 的 retro，人批了）
- 落点：`idea-loop:decision-rules` 的「PR 流程里『代价相称』只定推荐」一节
- 旧文：
> 到了 PR 流程（停下汇报和 review 轮次），边缘情形（只在兜底路径或罕见异常里出现、不丢东西）照旧是「要你决定」，「代价相称」只用来定推荐，不进「已按规则处理」
- 新文（规则加例外）：
> ……照旧是「要你决定」。例外：碰到时这一步不执行、原样交给人，或者能恢复（比如遗留的东西还留在主分支上、人说一句就能补），这种不丢东西能被指出来的，照规则接受成已知限制，列进「已按规则处理」，依据写它碰到时会怎样，人可以推翻。

- 例子：

**候选**（来自 #55 的 retro，人批了）：PR 流程里的边缘情形，碰到时这一步不执行、原样交给人，或者能恢复的，照规则接受成已知限制，列进「已按规则处理」，人可推翻。

**张力**：原节是有意设的保险（「用户会不会丢东西这个判断本身可能判错，判错的代价是丢用户的数据」）。这条只放宽「不丢东西能被具体指出来」的那部分；指不出来的仍是「要你决定」。决定记录：`docs/raw/decisions/55.md`。
