# idea-loop：issue-session 里人问 spec 怎么跑时，先核 spec 原文、配一张走一遍的图

- 信号：纠正与追问
- 落点：`issue-session` 的「spec 交给人审」那一段加一条
- 旧文：无
- 新文：「人在审 spec 时问『这套东西怎么运行 / 某个数字怎么来的』：先对着 spec 原文（和它引用的代码）核对再答，答里注明依据的是哪一节；spec 没写的，说『spec 没写』，不按自己的理解补。第一次讲运行机制时，用一个具体的改动（例如『改一个提示词』）从头走到尾，配一张时序图或流程图（`idea-loop:evidence` 的画法），标出每一步调哪个服务、调几次。」
- 例子：人审 spec 时问「改一个提示词，离线评测怎么跑」，追问三轮、要了一张图才清楚；重议时 AI 凭印象把 spec 写明的「基线存一份反复用」讲成「每次都跑三遍」，人差点在一个不存在的问题上做决定。

- 状态：在池里
