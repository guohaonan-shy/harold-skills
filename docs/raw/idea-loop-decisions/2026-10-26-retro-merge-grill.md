## 本轮决议

| 议题 | 决议 |
|---|---|
| retro 标记 | 分类照常按 plugin，加保留 label `retro` |
| 一批怎么凑 | 同一个 plugin 最早的至多 5 个，不满 5 个也出 |
| 多久出、占不占位 | 每个仓库每天最多一张整合卡片，已有整合会话不出；标题不是「<仓库名>#<号>」格式，不占位；放「实现中」 |
| 整合会话怎么走 | 合成一份 spec → 切工单 → 实现 → pr-review 与 skill 测试，全程不等人，人第二天看 |
| 测试 | 照改规则的现有规则；回放材料从 issue、决定记录、来源 PR 拼，拼不出标「无法回放」；retro 以后开 issue 写上这些材料 |
| 状态与不合 | 不要的条目：不做关 not planned，要讨论回普通队列；其余合并时关 |
| 存量 | 13 个打 `retro`；#80、#86、#87、#99 留普通队列 |
| 要人定的事 | 不停，按推荐先做，第二天在「要你确认」里列出 |
| 叫法 | retro 整合、整合会话、整合卡片 |
