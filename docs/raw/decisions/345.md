## 题 1：design-archive 被顶替时怎么办（夜里按推荐定）

- 类别：方案形状-有等价退路就不停
- 摆给人的：分拣给的两种（规则里写工具名对不上就停下 / 另开 issue 给它加开场确认），夜里另推荐第三种：工具不在就改用命令行（七个入口命令行也有、同一份 JSON）
- 人的原话：无（夜间模式，人不在，按推荐定，写进 PR #407 的「夜里替你定的」）
- 做法：按推荐写进 spec 和维护约定；后来整个 PR 关闭，这条随之作废
- 情形：插件自带的 MCP 有一份等价的命令行入口
- 处置：工具不在就改用命令行，不停下
- 理由：换命令行不丢东西，停下只多让人动一次配置
- 不自动的：否
