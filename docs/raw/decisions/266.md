## 题 1：triage 卡片占不占主队列的上限

- 类别：上限-按推荐
- 摆给人的：单独上限 3 / 共用主队列 10，推荐单独上限 3
- 人的原话：「单独上限 3 (Recommended)」
- 做法：triage 会话加还没点的 triage 卡片合计不超过 3；原上限 10 只数 in-progress、in-review
- 情形：新加一类要人在场的会话，跟实现会话抢同一个上限会被饿死
- 处置：按推荐单独计上限
- 理由：人一次接不住太多 grill；不跟 todo 抢位
- 不自动的：否

## 题 2：magi 里 triage 的 issue 怎么交出

- 类别：运行环境差异-按推荐
- 摆给人的：也直接开 / magi 不派 triage，推荐也直接开
- 人的原话：「也直接开 (Recommended)」
- 做法：magi 调度直接开 triage 会话，受上限 3 约束，会话写好 spec 草稿后停下等人
- 情形：桌面端靠卡片让人定时机，magi 没有卡片
- 处置：按推荐直接开
- 理由：讨论时机仍由人定，只是草稿先写好
- 不自动的：否
