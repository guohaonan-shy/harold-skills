## 题 1：规则改完怎么证明让 seo-brief 变了

- 类别：验收-规则改动回放还是文字检查
- 摆给人的：A 写回放用例（2026-10-27「toefl speaking topics」新开页，站点仓库 5d7148f6），PR 开出后当场跑，约 1–3.5 美元加两次 SERP credits（推荐）/ B 只做文字检查，等下一个新开页 issue 时人在 grill 里看
- 人的原话：「A 回放一次（推荐）」（选项单选）
- 做法：spec 的「规则验收」一节定成 A；runner 的 `--run-large --worktree … --repo <站点仓库>` 能跑跨仓库用例，不改 runner；无头会话里 OpenSEO 连不上就退到文字检查并在 PR 里写明
- 情形：改 skill 规则文字，回放要用付费外部服务、用例的提交在另一个仓库
- 处置：按推荐，写回放用例
- 理由：无（人没说）
- 不自动的：是（花钱）
