## 题 1：margin 和 gap 排出同一位置却报 position-drift，怎么改

- 类别：grill-按推荐
- 摆给人的：不再比 margin 和 gap（推荐）/ 盒子没偏就不报 margin / 不改
- 人的原话：「不再比 margin 和 gap（推荐）」
- 做法：spec `ui-measure-matrix-gaps` 定为从测量属性删掉 margin、gap，padding 照比
- 情形：改一条已写下的容差规则，依据只有 issue 的报告和实测
- 处置：照推荐
- 理由：位置的结果由盒子 top/left/width/height 判，margin/gap 只是排版手段
- 不自动的：否

## 题 2：像素层只截一个锚点区域的矩阵字段叫什么

- 类别：起名
- 摆给人的：pixelAnchor（推荐）/ clip
- 人的原话：「pixelAnchor（推荐）」
- 做法：矩阵格字段定为 `pixelAnchor`
- 情形：给公开的矩阵 JSON 加字段
- 处置：照推荐
- 理由：跟已有的 byAnchor 一路，不跟 Playwright 的 clip（矩形）混
- 不自动的：是（术语：起名）
