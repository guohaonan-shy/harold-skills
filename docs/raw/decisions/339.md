## 父会话定的

- 一个命令 `idea-loop`，放插件 `bin/`；hook 里仍写 `${CLAUDE_PLUGIN_ROOT}` 全路径。
- 按模块分子命令；新增 worktree、issue 挡路关系、git 落地、`gh pr` / `gh issue` 封装、静态服务器、DESIGN.md 官方 lint / diff。
- 照 poteto/noodle（`82d2921`）：登记表 + 扫 skill 的测试；易错操作做成带护栏的子命令、报错给下一条命令；hook 只拦不做事（拦手改 status label、手写 `git worktree remove`）。不照搬二进制分发、靠环境变量开护栏。
- Mac 本地与 magi 都要能用，命令每次运行时自己判断环境。
- runtime 不再是 skill：能进命令的进命令，各环境对照表变命令数据，SessionStart 照旧注入，子代理用 `idea-loop runtime show <能力>`；browser 的三条规矩并进去，browser skill 删掉。
- lint 只由自动触发器跑；要等一组改动做完才能判的检查放进落地命令当护栏；skill 显式调的 5 个格式检查挪进交回 / 落地命令。
- 包装别的命令行：`idea-loop agent codex run|image`、`idea-loop agent claude run`，直接起 `codex exec`，超时连子进程树结束；删 `codex-companion.mjs`，setup 预检改查 `codex`。理由：companion 每次起常驻 broker 从不退出，本机查到 154 个 broker、1205 个进程、约 3.76 GB，最老 23 天。
- 去掉 pr-reviewer 子代理（Harold：多余）；pr-review 主会话直接并行起 Spec、Standards 两个 Codex 进程。
- #302 补充（#339 评论，来源 PR #372）：各层 `index.md` 生成、slug 全局唯一、删后查死链、ADR 文件名四位编号递增，交给命令行。
