## 候选 1：范围题怎么推荐，按「影不影响这次交付」分

- 信号：对题的选择（6 次：本会话题 5，#125、#266、#55、#149、#180）加人自己说的方向
- 原话：「影响这个spec实现的问题在这个pr里修复，上线会有影响的重要问题在pr里修，其余的按照我们的流程进入候选」

- 归并：无
- 验证：回放用例：提交 `314a633`；输入「我们先根据最新的scope讨论下，skill的改动如何验证，参考potato关于这个的观点，我们来讨论下，然后看怎么做」；题「被推荐并进当前 PR 的，是不是只有影响这份 spec 实现或上线有影响的问题？」
- 结果：改成（按人的原话重写）后批·开 issue（https://github.com/guohaonan-shy/harold-skills/issues/313）
