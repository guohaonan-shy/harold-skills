## 题 1：本机对 runtime 的特殊做法放哪、谁去读

- 类别：方案形状-按推荐
- 摆给人的：home 里一份、runtime 去读（`~/home/RUNTIME.md` 一类，挂 0.2.0、PR 开到 release 分支）/ 现在就做、放 `~/.idea-loop/`、PR 开到 main / 不改插件、指针放调用方；推荐第一个
