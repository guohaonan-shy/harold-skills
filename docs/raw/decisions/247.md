## 题 1：在本机真搬家放在哪一刻

- 类别：落地顺序
- 摆给人的：A 0.2.0 装上后一次做完（#247 的 PR 先进集成分支，集成分支合进 main、本机升到 0.2.0 后一口气跑完五步）/ B #247 实现时就跑（harold-skills 删 `docs/` 跟 #247 的 PR 进集成分支，Toeflair 的删文件 PR 压到 0.2.0 装上后再合，中间写进 `docs/` 的要再同步）；推荐 A
- 人的原话：选了「0.2.0 装上后一次做完（推荐）」
- 做法：A
- 情形：本机装的 idea-loop 是 0.1.14，从代码仓库的 `docs/` 读写；Toeflair 有 4 个开着的 PR 改了 `docs/`（#977 #966 #784 #486），调度开的会话一直往 `docs/` 写
- 处置：spec 的「什么时候跑」「实现决策」写 A；#247 的 PR 合进集成分支后 issue 继续开着，等本机真跑完、两个删文件 PR 合并才 done
- 理由：插件和文件位置同时换，复制和删除之间没有空档
- 不自动的：否

- 做法：A
