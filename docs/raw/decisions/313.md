## 题 1：回放三次只过一次，验收怎么算（D1）

- 类别：验收-回放不稳定
- 摆给人的：A 照现在合 / B 用新版 runner 再跑 3 次按多数定、去掉输入开头的斜杠命令 / C 删用例；推荐 B
- 人的原话：「我选择B，然后版本用patch」
- 做法：新版 runner 重跑 3 次（Codex 评委、核对改后用上了改动），多数不过，交回 D2
- 情形：回放唯一一次「过」用的是旧评委、输入替会话读了规则
- 处置：花钱重跑，按多数定
- 理由：无
- 不自动的：否
