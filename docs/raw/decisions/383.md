- 类别：范围-相邻同类入口
- 摆给人的：审核报告里列为已知限制（本仓库没有多仓库配置，找不到真实路径），问人要不要现在修或开 issue；推荐不在本 PR 里修
- 人的原话：「合并吧，你说的限制在0.2.0的home repo会处理」
- 做法：不修、不开 issue，PR #413 直接合并
- 情形：review 发现 spec 范围外、当前仓库走不到的同类入口
