## 题 1：「画布在执行方 worktree 里有一份」这句事实写在参考的两处

- 类别：单一事实来源-spec 定的保留与规则冲突
- 摆给人的：A 两处都保留，靠新文档检查钉住一致 / B「输入」一节删到只剩指针，推荐 A（review 第 1 轮 C1）
- 人的原话：无（夜间模式，人不在，按推荐）
- 做法：A，代码不动；记进 PR 描述「夜里替你定的」，人合并时没有推翻
- 情形：spec 有意保留一句正确的事实，与「每个意思只放一处」冲突，且已有文档检查同时守住两处
- 处置：两处都保留
- 理由：spec 明确选了保留，检查已把两处绑在一起，漂开会当场变红，再精简收益小
- 不自动的：否

## 题 2：合并

- 类别：合并
- 摆给人的：审核报告交出后等人说合并
- 人的原话：「没啥问题就合并吧」
- 做法：合入 main（解版本冲突、按 patch 重升到 0.1.42、全量测试过），归档 review loop，合并，#375 翻 done
- 情形：审核报告无要人定的事
- 处置：合并
- 理由：人看过报告
- 不自动的：是（合并改了代码的 PR）
