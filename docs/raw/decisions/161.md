## 题 1：explorer 读 spec 的范围怎么定

- 类别：agent 读法-对齐上下游
- 摆给人的：保持只读「测试决策」加一句理由 / 加读「实现决策」/ 全放开对齐 implementer（第一次推荐保持只读；人追问背景后改推荐加读「实现决策」，并加「关掉不做」）
- 人的原话：「加读实现决策」
- 做法：spec explorer-reads-impl-decisions：explorer 读「测试决策」+「实现决策」，后者只当找位置的起点，笔记仍只写指针
- 情形：下游 agent（implementer）放宽了读 spec 的范围，替它做前置工作的 agent（explorer）还停在旧读法
- 处置：只加读下游拿来找位置的那一节，不全放开
- 理由：explorer 的本意是替并行 implementer 先做重复的查找；其余节不产出指针
- 不自动的：否
