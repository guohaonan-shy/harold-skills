## 题 2：#80 转来的「全局 CLAUDE.md 例子不带具体项目」并不并进这份 spec

- 类别：范围-并入相邻候选
- 摆给人的：并进来（推荐，补在「剪枝」相关性一条）/ 不并、开新 issue
- 人的原话：「我觉得#80的核心我觉得是要区分什么纬度的文件可以带项目纬度的信息和few shot，什么不能。比如idea-loop我理解属于通用工作流，不能带有一丝项目相关的信息；全局纬度的claude.md也是一样的。而且内容尽可能的精简，retro新来一个case不能直接append，而是要结合candidate分析，这个内容到底可以和现有的skill怎么结合，以及这块内容要如何验证这个改动确实对于之前的问题解决了。」

- 理由：通用工作流和全局文件不带任何项目信息；新内容要先归并、写明怎么验证
