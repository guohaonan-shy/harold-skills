## 题 1：用哪种办法认出品牌词的站点链接不是蚕食（审 spec 的待定）

- 类别：方案形状-被人推翻
- 摆给人的：A 排除品牌词（品牌名从域名推）/ B 认站点链接的形状 / C 都做，推荐 A
- 人的原话：「这个点我倾向于在seo.md设置一个品牌词的章节，用户可以自己设定品牌色来排除这种情况。」
- 做法：品牌词由人写在 SEO.md 新开的「品牌」节，蚕食判定排除含品牌词的查询；不做形状识别。对话落 [[2026-10-27-brand-terms-cannibalization]]
- 情形：推荐的方案靠插件自动推参数，人要改成由人显式配置
- 处置：人改了方案形状
- 理由：人先追问了蚕食的定义和误报的依据，弄清后自己提出由用户设定品牌词
- 不自动的：是（方案形状被人提出第三条路）

## 题 2：品牌词放在 SEO.md 的哪里

- 类别：grill-按推荐
- 摆给人的：新开「品牌」一节 / 放进「站点」节，推荐新开一节
- 人的原话：「新开「品牌」一节 (Recommended)」（选择题）
- 做法：SEO.md 从六节变七节，新开「品牌」节，键「品牌词」
- 情形：配置放法，两种放法用户可感的差别只在文件结构
- 处置：按推荐
- 理由：无
- 不自动的：否

## 题 3：SEO.md 没填品牌词时，蚕食判定怎么办

- 类别：grill-推荐被人改
- 摆给人的：从域名推一个 / 不排除，推荐从域名推
- 人的原话：「不排除」（选择题）
- 做法：没填品牌词时照旧判蚕食，不从域名推
- 情形：配置缺省时，插件要不要自己推一个值
- 处置：人选了不推
- 理由：无（与题 1 同一方向：参数由人显式写）
- 不自动的：否
