## 题 1：spec seo-autopilot 起草时自己补的六条实现决策，照草稿定还是逐条 grill

- 类别：grill-按推荐

- 人的原话：「6 条照草稿定」

- 情形：功能级 spec 的方向已在 issue 里跟人定过，起草时按 issue 原文补的实现细节
- 处置：照草稿定
- 理由：补的决定都能指回 issue 原文
- 不自动的：否

## 题 3：AI 搜索可见性方向每周额度推荐 0，改 spec 说法还是让它花钱（review 第 1 轮 S1）
