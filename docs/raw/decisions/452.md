## 题 6：概要里允许哪些代码叫法

- 摆给人的：只放开路径 / 概要里全放开 / 照旧全拦，推荐只放开路径（照旧全拦会让文件树、文件布局 diff 两块整块用不了）
- 人的原话：「只放开路径，你是担心runtime control flow 这种格式不允许，这个要不用我们的evidence（excalidrawer的时序图）描述？你觉得这个是否OK？」
