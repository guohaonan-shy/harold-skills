## 本轮决议

| 议题 | 决议 |
|---|---|
| 改原文还是另发 | 回复、评论是发言：不改原文，另发新的；文档、PR 描述是当前状态：直接改成最新 |
| 新版本写什么 | 不固定格式，写清比上一版改了什么、谁定的改动 |
| 评论放多少 | 第一句是结论和要他做什么；只放他做这件事用得上的；有文档只摆结论和决策点，没有放末尾折叠区 |
| 旧评论 | 不动 |
| 适用范围 | 所有以 Harold 身份对别人说话的内容，不分平台 |
| 署名 | 不署名，去掉「🤖 idea-loop：」开头和「由 Claude 代发」 |
| 规则放哪 | 表达方式只写进 `~/home/AGENTS.md`；idea-loop 不放表达方式，只改机械部分（标记、归档评论开头、引用前缀的 skill 文字） |
