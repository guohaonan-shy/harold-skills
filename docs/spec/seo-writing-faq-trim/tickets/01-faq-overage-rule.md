# 01 — seo-writing 的 FAQ 规则加上「条数超标先看搜索词」

**Blocked by**：无——可立即开工
**设计冻结**：不涉及 UI

## 要建什么
idea-loop 插件里写站点文章的 skill（seo-writing），第 4 步「写」的 FAQ 那一条，现在只说每条问题要是用户真会搜的说法，没说条数超出项目规范时怎么办。改完后，写文章的 agent 读到这一条就知道：条数超出项目规范时，先用 OpenSEO 的 `get_search_console_performance` 拉这一页近 3 个月的搜索词，逐条对到每个问答；没有可见搜索词、内容又和别的问答或正文重复的删掉；删完仍超，写进交回的「需要人决定的事」，附逐条对照（问答 / 对得上的搜索词与展现 / 判断），并写明两点限制（Search Console 隐藏低展现的长尾词，没有可见搜索词不等于零；问答被 AI 回答引用的价值它量不到）；页面还没上线或拉不到数据，写明原因直接交给人。

spec 给的文字（可为通顺小改，意思不变）：「条数超出项目规范时，先用 OpenSEO 的 `get_search_console_performance` 拉这一页近 3 个月的搜索词，逐条对到每个问答；没有可见搜索词、内容又和别的问答或正文重复的，删掉；删完仍超，写进交回的『需要人决定的事』，附逐条对照（问答 / 对得上的搜索词与展现 / 判断），并写明两点限制：Search Console 隐藏低展现的长尾词，没有可见搜索词不等于零；问答被 AI 回答引用的价值它量不到。页面还没上线或拉不到数据，写明原因，直接交给人。」

加在 FAQ 那一条的末尾，同一个列表项里；不另开 reference 文件，不升 plugin 版本，不动别的条目。文字里不出现任何具体项目的名字或场景。
