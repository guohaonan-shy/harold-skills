# 01 — seo 不再单独排队：所有 issue 一个队列

**Blocked by**：无——可立即开工
**设计冻结**：不涉及 UI

## 要建什么

调度不再有「独立队列」：项目「issue 分类」一节里父类说明末尾的「（独立队列，上限 N）」不再让那个分类单独排队，括注只是普通说明文字。所有待验证 issue 在一个队列里出卡片，上限 10，会话待在一套阶段 section（审核中 / 设计中 / 实现中）里，不再有「seo 审核中」这类加了分类名的 section。

对人可见的变化：调度会话的汇报只有一行队列；issue 会话归位时只用那一套 section；`seo-setup` 加 seo 分类时不再写括注；`issues` 脚本不再有列队列的命令，取候选也不再接受指定队列的参数（给了就报不认识）。说到独立队列的文字（调度、issue 会话、spec 状态、分类一节的写法说明、seo 的 README、插件 README）一起改掉。

## 验收标准

- [x] 分类一节里带「（独立队列，上限 5）」的 `seo` 父类：取候选时它的 issue 跟别的 issue 一起出，按号排序；不再有单独取它的方式
- [x] 脚本的用法说明里没有列队列的命令和指定队列的参数；调用已删的命令报「不认识的命令」
- [x] 调度、issue 会话、spec 状态、seo-setup、setup 的分类写法说明、seo README、插件 README 里不再说「独立队列」
- [x] 全量测试通过
