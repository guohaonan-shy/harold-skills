# 04 — og skill：几种更好看的分享卡版式，照项目品牌渲染

**Blocked by**：02 — SEO.md 记下项目的写作检查配置和配图取值
**设计冻结**：不涉及 UI

## 要建什么
idea-loop 的 seo 组新增一个可被模型调用的 skill `og`：给一篇文章出 OG 分享卡（1200×630），放到图片目录、写进 frontmatter 的 OG 字段。

- 插件自带 2–3 种版式（HTML 模板），只用 DESIGN.md 的 token（色、字体）和「og-card」组件的配方（版式选哪种、字号层级、logo）渲染；没配用插件默认版式和中性配色。现在 Toeflair 的模板只是渐变底板加 logo、kicker、标题、副标题，人评价「太简单了」：新版式要明显更有设计感（例如强排版的大标题、带主体图或数据的分栏、品牌色块构图），每种版式在标题长短、中英文下都不溢出。
- 取值读法、找 DESIGN.md、没配时的退路，跟 `cover` 一致（`SEO.md`「配图」节 + DESIGN.md）。
- 渲染用浏览器把 HTML 截成 PNG，重渲后对 md5 防缓存。
- 选默认版式：用 Toeflair 的取值（读它的 DESIGN.md 和一篇已发布文章的标题，只读不改它的仓库）把每种版式渲成真图，放进 PR 给人挑，人定了的版式作默认。夜间模式下按推荐定一种作默认，记进 PR 描述的「夜里替你定的」，人可推翻。
- description 只做路由，触发词覆盖「做 OG」「分享卡」「重做 OG」。
