# 子 agent 交回后卡住：那一轮的模型请求丢了

> #292 存在：子 agent 交回之后，编排者那一轮只有一句「No response requested.」，流程停到人来问；但这句话是平台合成的，模型根本没被调起来，详情在「问题陈述」

## 问题陈述

### 交回之后流程停住，直到人开口

编排者（跑 implement、pr-review 的 issue 会话）把工单、review 交给后台子 agent，子 agent 的交回作为一条消息送进会话。这条消息本该让模型核对、落地、汇报。卡住时，这一轮之后只有一句「No response requested.」，之后没有东西再叫醒会话，人回来问「卡住了？」才接上。进程重启过的，还会多一条过期的「stopped」通知，让人以为子 agent 断了。

测了什么：2026-11-16 扫本机全部 Claude 会话记录（`~/.claude/projects/*/*.jsonl`，含 TOEFLAIR 与 harold-skills），按交回消息自带的标记（`origin.handback: true`）认出交回，去重后 **1967 次**；其中 **39 次**交回之后的第一条回复就是那句「No response requested.」，约 2%，分布在 2026-10-19 到 11-15。卡住的交回来自 implementer 21 次、pr-reviewer 11 次，其余 7 次来自 designer、explorer、ui-master、ui-reviewer 等。

一个具体例子（TOEFLAIR 2026-11-09，robots.txt 工单的 issue 会话）：

| 时间 | 会话记录里有什么 |
|---|---|
| 08:58:30 | implementer 交回 `status: landed` |
| 08:58:30、08:58:33 | 会话发出两次模型请求 |
| 之后 11 分钟 | 一条记录都没有 |
| 09:09:14 | 进程重启；平台给这一轮补写「No response requested.」，`model` 是 `<synthetic>`，输出 0 token |
| 09:09:15 | 补发过期的「stopped」任务通知；模型没有接着跑，下一轮是人开口 |

本该是：交回到达后，模型读它、核对提交、落地。

### 根因

那一轮处理交回的模型请求没成，平台在进程重启时用一句合成回复把它关掉。

- 39 次按那一轮留下的痕迹分：**15 次**记录了 `Connection dropped (ECONNRESET)`，平均重试十几次都没成；**20 次**请求发出后一条记录都没有，直到进程重启（多半是连接挂住，记录证明不了是网络、API 服务端还是桌面端进程）；**4 次**请求都没发出，进程就没了。
- 「No response requested.」不是模型写的：全部 123 条里 122 条是 `model: <synthetic>`；唯一一条模型写的（2026-10-23）跟在普通任务通知后面，不是交回。
- 39 次里 Stop 钩子一次都没触发；正常处理的交回，大多留有 Stop 钩子的执行记录。

修正：原先认为模型读了交回、把它当成不用回的通知结束了这一轮（issue 的「已确认原因」），实测是模型没被调起来。这也解释了为什么用户级 CLAUDE.md 和会话里写的「收到交回必须处理」一直拦不住：模型没看到那一轮。

## 方案

不改 idea-loop。人在 2026-11-16 的 triage 会话里定的：「看起来核心是网络的问题，修改spec，然后关闭issue吧」。

撤掉的候选，各自为什么不起作用：

- **Stop 钩子**（issue 正文提的，结束一轮前读会话记录，挡住没调工具就结束的交回轮）：那一轮没有模型运行，Stop 事件不触发；39 次里 0 次。
- **交回最后一行写明接收方的下一步、implement / pr-review 每个出口交固定结果块**（issue 评论提的）：模型没读到交回，写得再清楚也没人读；也没找到「模型读了交回却不往下走」的实例，单独当改进做没有依据。
- **在 hooks.json 里加检查，下次人开口或会话恢复时指出漏掉的交回；或派活时定一个兜底唤醒**（本次调查提出的）：能缩短人发现的时间，但不碰网络这个根因，人定了不做。

## 测试决策

| 变的是什么 | 仪器 | 本次 |

## Out of scope

- 网络、API 服务端或桌面端进程那一侧的问题：不在这个仓库。
- 已知限制：交回后卡住照旧约 2%，照旧要人回来开口才接上；看到过期的「stopped」通知时，子 agent 的交回可能早已在会话里。
