# 01 — seo-brief 新开页的角度候选逐篇对照站内同主题文章

**Blocked by**：无——可立即开工
**设计冻结**：不涉及 UI

## 要建什么

用 `idea-loop:seo-brief` 为一个目标词写「新开页」的 brief 时，agent 在看现状那一步不止拿到站点的可链接页面清单，还从清单里挑出和目标词同主题的已有文章，逐篇取回 H2–H3 大纲和一句论点（抓不到的写明，没有同主题的写「无」）。到出角度候选时，每个候选都和这些文章逐篇对照论点与主要小节：重合的换一个角度，或写明重合的是哪一篇哪一节、新页在那之外补的是什么；不重合的写「无重合」。brief 输出结构里每个角度候选多一行「对照：…」。

只改 seo-brief 这一个 skill 的三处：看现状一步的「新开页」及其完成条件、角度候选一条及其完成条件、输出结构的角度候选。第 1 步按 Search Console 判自相蚕食、「改已有页」模式保持不动。新增文字用正向措辞，不带任何真实项目的例子。

同时写一个 retro 回放用例，验收这条规则：取一个站点仓库 2026-10-27 为「toefl speaking topics」新开页那次（站点仓库提交 `5d7148f6`，本地 remote 为 Tofelair），prompt 是当时让 brief 产出的那句话，是/否题：「brief 的角度候选有没有逐篇对照站内同主题的已有文章、写明重合与否？」。它用 OpenSEO 付费查询，是大用例，写明待跑，由编排者在 PR 上用加了 `--repo <站点仓库>` 的大用例命令当场跑。

## 验收标准

- [x] seo-brief 的看现状一步，新开页要求从页面清单里挑出同主题的已有文章，逐篇取大纲和一句论点；抓不到的写明。
- [x] 看现状一步的完成条件写明：新开页有可链接的页面清单，和一份同主题文章清单（每篇有大纲和论点，或写明抓不到；没有同主题的写「无」）。
- [x] 角度候选一条要求逐篇对照论点与主要小节，重合的换角度或写明重合哪一篇哪一节、新页补什么；该步完成条件包含「每个角度候选都有对照结果」。
- [x] 输出结构的角度候选每条带一行「对照：…」。
- [x] 第 1 步自相蚕食检查与「改已有页」模式的文字没有变。
- [x] 插件不带项目信息的检查通过（no-project-leak 测试）。
- [x] retro 回放用例已写在回放用例目录下，格式照已有用例，commit、repo 指向站点仓库那次提交，标成大用例。
- [x] retro 候选池里候选 92 的状态改成「已开 issue（#188）」。
- [x] 调过 `writing-for-agents`，交回 `verified` 里每个改到的 skill、agent 定义、skill 参考文件一行杠杆。
