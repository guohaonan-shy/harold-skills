# 05 — critic rubric 与评分自洽校验

**Blocked by**：04 — design plugin 退役并入 idea-loop
**设计冻结**：不涉及 UI

## 要建什么

让"9 分"有一个能依赖的定义，并且让代码守住**分数不能脱离 finding**。

**rubric**（评委每轮读的就是它）定两张梯子：四档严重度，每档锚定顶级工作室 AD 会做的动作；以及分数带，由本轮最差的那条 finding 定上限、同带内按数量微调。停止阈值写在 rubric 里，评委看得到——它靠自洽校验守，不靠藏。

评委只评一件事：**对照它想要的美学，执行到了什么程度**。可用性启发式、对比度与 a11y、DESIGN.md 合规各归原有的 gate，不进这份 rubric。

**自洽校验是一个纯函数**，不替评委打分：吃 finding 数组、评委给的分数、上一轮的最差严重度，吐两件事——本轮有效还是无效（分数落在最差 finding 允许的带之外就是无效，重跑评委），以及停止判定（继续 / 达标 / plateau / direction）。

finding 的形状是闭集，也由这个函数守：维度五值、严重度四值、kind 三值，且 kind 与严重度的组合受限。

两张梯子是 spec 里谈定的决策载体，原样内联在这里（出处：设计工作流 v2 spec 的 critic rubric 一节）：

| 严重度 | 定义 | AD 的动作 | 对应维度 |
|---|---|---|---|
| P0 | 画面读出来的美学和它想要的不是同一个；或命中 slop catalog 任一条 | 重开方向，不改稿 | Philosophy；Specificity 里的 filler |
| P1 | 眯眼测试失败，视线落不到一处，主次竞争；或多个 flourish 打架 | 这一块打回重排 | Hierarchy；Restraint |
| P2 | 字号、字距、间距、对齐、对比"接近但不对"，存在能用尺子量出来的修法 | 红笔标注，再过一轮 | Execution |
| P3 | 会注意到但不会因此拦发布的打磨点 | 顺手改，不拦 | 任一维度的余量 |

| 分 | 最差 finding | 含义 |
|---|---|---|
| 10 | 无 | 找不出自己会动手改的地方 |
| 9 | 仅 P3，不超过 2 条 | 工作室会原样发布 |
| 8 | 有 P2，无 P1 | 会批准，但要再过一轮红笔 |
| 7 | 一条 P1 | 某块要重排 |
| 6 | 两条以上 P1，或 P1 叠多条 P2 | 多处重排 |
| 4–5 | 有 P0 | 方向漂移或 slop，重开 |
| ≤ 3 | 多条 P0 | 不是执行问题，是 brief 问题 |

## 验收标准

- [x] rubric 作为 plugin 级 reference 落在设计那组内容里，四档严重度与分数带两张表齐全，停止阈值 9 明写
- [x] rubric 写明评委只评"对照它想要的美学执行到了什么程度"，并点名可用性启发式、对比度与 a11y、DESIGN.md 合规各归哪个既有 gate
- [x] rubric 依赖的现有材料（五维 critique、P0–P3 定义、slop catalog 与 reference-averaging 禁令）**按名引用，不复制正文**
- [x] finding schema 闭集：维度五值、严重度四值、kind 三值；合法组合为 P0 一律 direction，P1 可 pattern 或 craft，P2 与 P3 一律 craft
- [x] 自洽校验纯函数：输入 finding 数组、评委分数、上一轮最差严重度，输出本轮有效 / 无效 + 停止判定（继续 / 达标 / plateau / direction）
- [x] 单测覆盖这些黑盒判据：2 条 P3 给 9 → 有效且达标；2 条 P3 给 10 → 无效；一条 P1 给 9 → 无效；一条 P0 给 5 → 有效且判 direction；连续三轮最差都是 P1 → 第三轮判 plateau；灌一条 kind 为 direction 的 P2 → schema 校验失败
- [x] 这个函数不需要 mock，不碰浏览器、不碰模型
- [x] 它与已有的单测共用同一条运行命令

## 选中的存量回归

本仓库**无 test-cases 库**。真实存在的套件是 lint 规则单测与视觉比对函数单测，与本张共用运行命令，**跑一遍确认三套都绿**。

另有一处纸面风险：本张的 finding 形状必须与视觉比对函数输出的 finding 形状同构（同一种阅读方式），开工时对照一遍，不要长出第二种 schema。
