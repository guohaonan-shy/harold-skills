# 06 — 切票时的设计冻结字段消费 design 产出

**Blocked by**：05
**设计冻结**：不涉及 UI

## 要建什么

切票时识别到一张票涉及 UI 的改动，检查设计冻结产物（05 里 grill 移交设计总入口后带回来的预览 HTML 路径 + 冻结状态摘要）是不是已经存在，把它按约定格式写进票头的"设计冻结"字段；没有这份产物，字段就落"未冻结、不可开工"。

约定格式形如：预览路径 + 一行还原度/决策记录摘要，让实现阶段的人能核实这不是一句空话——具体的数字与措辞由设计总入口产出时自己填，切票这一步只负责按格式誊写。

## 验收标准

- [ ] 有冻结产物时，票头的设计冻结字段包含预览路径和一行可核实的还原度/决策记录摘要
- [ ] 没有冻结产物时，字段落"未冻结、不可开工"，实现阶段据此挡住这张票的开工
- [ ] 延续 05 的最小目标项目骨架跑一次端到端干跑：grill 产出的路径和摘要，切票消费之后字段格式正确、内容对得上

## 选中的存量回归

无 test-cases 库，本仓库也没有既有的自动化测试套件——本次验收全靠上面这几条人工核对。
