# 06 — uiux-imagine：发散，准出一份方向说明

**Blocked by**：04 — design plugin 退役并入 idea-loop
**设计冻结**：不涉及 UI

## 要建什么

一个**只能人调**的 skill。spec 落成"等设计冻结"之后，人跑它：在**还没定下来的最高高度**上看到几个真正不同的变种，给方向性的话，调向到"方向没有要补的了"，准出**一份方向说明**写进 spec。

它每次都走，但大小随打开的高度伸缩——加一个 badge 不该出六套语言：

| 已经定了什么 | 在哪个高度出变种 | 种子作用 |
|---|---|---|
| 没有 DESIGN.md | 语言：配色、字体、形状、register，渲染成 style tile | 每个种子一套语言 |
| 有 DESIGN.md，结构没定 | 结构：块序、内容责任、页面 IA，灰盒 | 每个种子一种结构赌注 |
| 有 DESIGN.md，结构已定 | 布局与处理：模块构图、组件处理、状态呈现 | 每个种子一种处理 |
| 有边界的组件改动 | 组件：2 到 3 个选项的 Variant Board | 种子给处理方向 |

语言高度只在没有 DESIGN.md 时自动打开。已经有 DESIGN.md 的项目要人**显式说"重探语言"**才打开，产物是带日期的修订提案而不是悄悄覆盖——打破路径依赖是显式决定。语言高度一旦打开，要一路降到 surface：选完语言、写完 DESIGN.md，再在结构或布局高度出一轮变种，直到方向说明描述的是一个 surface 而不是一种风格。

**三条纪律**是这个 skill 的形状，不是建议：只接方向性的话（执行层的话停进待打磨清单，不当场改，否则它会偷偷变成收敛）；不提保真度（人在低保真下分不出两个变种哪个好，说明差别在执行层，按推荐选）；**没有评委**（人评的是方向，也不为会丢掉的变种付评委的钱）。

准出物**只有**一份方向说明。变种的渲染物和 contact sheet 只服务于人当下的反应，不往下传、不留存；落选的理由以文字进方向说明。

## 验收标准

- [x] skill 只能人调（与访谈、实现同一档），触发条件只有一个：spec 为等设计冻结
- [x] 四档高度规则与种子作用如上表，种子作用在**打开的那个高度**上
- [x] 语言高度只在没有 DESIGN.md 时自动打开；有 DESIGN.md 时要人显式说重探语言才打开，产物是带日期的修订提案或营销 register 分支，写不写回由人决定
- [x] 语言高度打开时一路降到 surface：选语言 → 写 DESIGN.md（固定八节、T1 五到八条底线、Case Law 从空开始）→ 再在结构或布局高度出一轮变种
- [x] 起点三种：完全空白时用 shell 生成随机串、每个种子独立派 subagent 定一套方向；已有 ambition 直接用 ambition 起步，不强制走种子；已有 DESIGN.md 时在约束内出清单并混一两个种子当 wildcard
- [x] 调向环：先列一批刻意缺乏细节的想法 → 渲染人挑中的几个（最低可分辨保真度）→ 人给方向性 note → 调向 → 迭代到人说方向没有要补的了 → 由模型写出方向说明
- [x] 三条纪律写进 SKILL.md：只接方向性 note、不提保真度、没有评委
- [x] 参考研究工具**不在第一批变种出现之前被读**；之后由人或模型提出的具名问题召唤，按布局 / UX pattern / style 路由到对应研究层；选定语言后可选做一次 styles 压力测试（表格、表单这类会塌的场景）
- [x] 方向说明固定七节：意图、高度记录、结构、变种裁决、待打磨清单、约束与素材、验收矩阵；写进 spec 实现决策下的「设计方向」小节
- [x] 闸门是人的：模型写，人改过并确认才算通过
- [x] 缺任一节 → 收工校验失败，不写 spec（可证伪）
- [x] 变种渲染物与 contact sheet 不留存、不往下传；落选理由以文字进方向说明
- [x] 收工告诉人去 `/clear` 再跑收敛那个 skill
- [x] 参考研究工具的路由 reference 改写成"被具名问题召唤"的契约：唯一硬规则（第一批变种之前绝不读）、问题的两个来源、三层路由、结果按 Can answer / Cannot answer / Keep-Change-Do not copy 三行记录、守 reference-averaging 禁令
- [x] README 两张表把它列进只能人调那栏；SKILL.md 主体 < 5000 字

## 选中的存量回归

本仓库**无 test-cases 库**。已有的三套 node 单测本张都不碰，无需跑。

真正的风险在**引用面**：本张要改参考研究工具的路由 reference，而那份 reference 现在被迁移过来的静态 UI protocol 按名引用。改完确认引用它的那几处措辞没有变成假引用。
