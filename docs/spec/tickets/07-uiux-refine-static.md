# 07 — uiux-refine：静态打磨环到冻结

**Blocked by**：05 — critic rubric 与评分自洽校验；06 — uiux-imagine
**设计冻结**：不涉及 UI

## 要建什么

一个**只能人调、且要求全新会话**的 skill。它读 spec 里那份方向说明和目标项目自己的 DESIGN.md 与 PRODUCT.md，**从 prompt 重建** preview，跑一条双模型打磨环收敛到可发布，人签字后冻结。

它**不读发散那一段的任何渲染物**——handoff 是一封写完整的信，不是"如上所述"。

**打磨环每轮两个角色：**

- **评委**是另一个模型的 subagent，每轮新开上下文，收到的只有当前截图、方向说明里的意图那一句、rubric。不给代码、不给历史评语、不给项目的 T1 底线（那是 lint 与 drift check 的活）。它吐一份 finding 列表**和**一个分数；分数与 finding 不自洽就判本轮无效、重跑评委。
- **执行者**是更强的模型，思考强度默认高、本轮最差为 P1 或进入 plateau 时更高。它先把散点 finding **聚成"本轮核心问题"一句话**，再按 kind 路由：方向级的停环交人，pattern 级的去查参考研究，craft 级的直接改。每轮 ledger 落一行：核心问题、查了哪层、选了哪个参考、改了什么。

**收敛规则**只有三条：校验通过的分达标就停；最差严重度连续两轮不降判 plateau，停下交人；出现方向级 finding 立即交人——人不该为一个评委修不了的方向问题付无限轮次。

静态构图收敛之后还有两轮独立的 pass：**减法**（评委带减法 brief 再跑一轮：去 glow、去渐变、去多余容器，图能说清就删标签，原生控件能用就不自造）和 **AI tells 清理**。"删"是独立目标，不是顺手。

**人签字时的反馈按性质分流**：执行性的再跑一轮评委，方向性的回发散那一段在对应高度重开。**refine 永不改方向。**

冻结时：画布、矩阵每格截图、ledger 进 raw 桶；spec 里的「设计方向」小节被「冻结摘要」取代，状态翻在飞——切票和实现从此各取所需。

画布的角色相当于一块 Figma 画布，所以它必须守实现环那三条环境约定，否则下游比对没有价值。

## 验收标准

- [x] skill 只能人调，SKILL.md 写明它要求一个全新会话（与实现同理）
- [x] 输入只有 spec（含方向说明）、目标项目根的 DESIGN.md 与 PRODUCT.md、plugin 自己的 references；**不读发散那一段的任何渲染物**
- [x] preview 从方向说明在 DESIGN.md 之下重建，工作文件落在 lint hook 盯得到的 preview 目录
- [x] 第一轮先消费方向说明里的待打磨清单，再进评委环
- [x] 评委每轮新开上下文，只收当前截图、意图一句、rubric；明确不给代码、不给历史评语、不给 T1 底线
- [x] 评委输出 finding 列表加一个分数；分数与 finding 不自洽 → 本轮无效、重跑评委（复用已建好的校验函数，不在 skill 里重写判据）
- [x] 执行者每轮先聚成"本轮核心问题"一句话，再按 kind 路由（direction 停环交人 / pattern 查参考研究 / craft 直接改），ledger 每轮落一行
- [x] 收敛规则三条：达标即停、最差严重度连续两轮不降判 plateau 交人、出现方向级 finding 立即交人
- [x] 静态构图冻结后有一轮减法 pass（评委带减法 brief）和一轮 AI tells 清理，二者是独立的两轮
- [x] 人签字的反馈按性质分流：执行性 note 再跑一轮评委，方向性 note 回发散那一段在对应高度重开
- [x] 画布守三条环境约定：稳定 data 锚点、字体走目标项目自己的加载方式、每个状态可用查询参数切
- [x] 冻结产物：画布、矩阵每格截图、ledger 一起进 raw 桶，配一份 `source_type: design-freeze` 的 raw md
- [x] spec 的「设计方向」小节被「冻结摘要」取代（画布的 wikilink、矩阵、阈值、ledger 一行摘要、状态矩阵与数据契约变更），状态翻在飞
- [x] 既有 gate 一条不少：lint hook、Nielsen 启发式、DOM 测量的对比度与 a11y、DESIGN.md drift check；Distill-back 只追加 T2，不改 T1 与 T3
- [x] README 两张表把它列进只能人调那栏；SKILL.md 主体 < 5000 字

## 选中的存量回归

本仓库**无 test-cases 库**。三套 node 单测里，本张只依赖评分校验那套（skill 调它，不重写它）——**跑一遍确认仍绿**，并确认 skill 里描述的判据与函数实现没有分叉。

另一处要实跑的是 **lint hook**：本张规定 preview 工作文件落在 hook 盯得到的目录，写一次 HTML 确认它真的触发。
