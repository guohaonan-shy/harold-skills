# 02 — 构成清单标来源，方向定下后的执行层意见改在选中那一版上

**Blocked by**：01 — imagine 拆成编排者 + uiux-imaginer
**设计冻结**：不涉及 UI

## 要建什么

方向说明里每个选中变种的构成清单，六项每一项后面都标出来源：`（人选定）` 或 `（模型代填）`。前者是人在变种之间选出来或直接给定的，后者是 imagine 收工时摆给人确认过的代填项。方向说明校验脚本把这个标记当成形状的一部分来查。

同时放开 imagine 纪律 1 的一处（spec §4.10）：

- 方向没定之前，执行层的话照旧拦进待打磨清单，不当场改。
- 人点名留下某一版之后，人**明说要当场看**的执行层意见，uiux-imaginer 改在选中的那一版上，构成清单里对应项记成人选定；人没说要看的，照旧进待打磨清单。

## 验收标准

- [ ] 方向说明校验脚本：选中变种的构成清单某项缺来源标记、或标记不是这两种之一时失败，报出是哪一项；两种标记都齐时与现在一样通过。补单测覆盖这三种情况。
- [ ] uiux-imaginer 收工写的方向说明，构成清单每项都带标记，过校验。
- [ ] 方向没定前说「插图再大一点给我看」：进了待打磨清单，变种板没改。
- [ ] 人点名留下 B 之后说同一句：uiux-imaginer 改在 B 上，构成清单里插图尺寸那项记成 `（人选定）`。
- [ ] plugin 脚本单测套件全绿。

## 选中的存量回归

无 test-cases 库。本仓库真实存在的是：

- **plugin 脚本单测套件**——方向说明校验脚本的已有单测（七节、构成清单六项）必须照旧通过，标记检查只是加一条。
- **baseline eval 的 refine 那一格的种子方向说明**——它是一份手写的 fixture，加标记检查后要同步补上标记，否则 refine 那一格会在开工前置上红。
