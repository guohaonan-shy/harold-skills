# 装傻 + 反向倒拉会议（play-dumb）

## 适用

- 对方有**决策权**但不行使，把"目标 / 预期 / 范围"模糊成你来定义
- 摘果型 / 推责型老板：让你先扛 → 解决了出来摘 / 出问题甩你头上
- olden-patterns 命中：§2 推卸责任 / §5 模糊施压（**当对方有决策权时**）
- 你独自承担硬扛过、被甩锅过 → 用户画像 `#strategy (outcome:: ✗)` 提示这条路走不通

## 不适用

- 对方是**同级**或**下级**——装傻 + 倒拉会议是对**有决策权但不行使**的人用的；对同事用反而是推托
- 紧急情况需要立刻动作（装傻反向倒拉会议会拖时间）
- 议题本身就是你独立 owner，没人需要决策

## 应对剧本核心

**不说"我没时间" / "我做不到"** —— 这是给对方的小辫子，他会马上转化为"那你还能做什么 / 是不是 ownership 不够"。

**说"我不太懂" / "我想确认下目标"** —— 这不是认怂，是把决策责任**反向**抛回他身上。决策权高的人对"被反问目标 / 范围"是非常不舒服的，因为他要么得给清楚的目标（这就锁死了他的决策责任），要么暴露自己也不知道（这就给了你拉第三方的理由）。

**核心三动作：**
1. **不接决策**："这个我不太懂，不太好直接定"
2. **倒拉会议**："能不能拉 X / Y 一起开个会，把目标和分工对一下"——指名拉**对方应该协调的依赖人**（让他自己去拉，**不是你去拉**）
3. **会上只参不决**：参会但不主动给方案。等他在多人面前定了目标 / 责任分工，你再承担**执行**层面的责任

**不承担决策 + 不承担"如果他不拉就推不动"的责任** —— 这两件事都不是你的活。

## 3 候选差异维度

reply-coach §7 生成时本策略的差异轴：

- **A. 保守版** —— "我对这个项目的目标 / 优先级理解可能不够，能不能先拉一下相关的 X / Y 把范围定下，我再按对齐后的方向推进"。语气最委婉，给对方面子
- **B. 标准版** —— "这块我不太懂，方向得拉 X / Y 一起对一下；目标和分工定了我再承接执行"。直接但不对抗
- **C. 微刺版** —— "这个范围我自己定不了。能开个会把 owner / 边界 / 验收标准明确一下吗？" —— 暗含"你没给清楚我没法干"

## 缺什么必须先 AskUserQuestion 问

按 conventions.md §4，缺关键 concrete 信息先问：
- **具体的"应该被拉的人"** —— 不要说"拉一下相关人"，要点名（"拉 PM 张三 + 工程 lead 李四"）—— 用户档案 + 群档案应该能给候选名单，没的话**问**
- **具体的"应该定的目标变量"** —— 是定 deadline？定 scope？定 owner？定 acceptance？—— 让 AI 不要笼统说"对一下目标"

## 措辞要领

- **不**说"我没时间 / 我做不了" —— 留小辫子
- **不**用"建议" / "我觉得" —— 这是接决策的姿态
- 用"我不太懂" / "想确认一下" / "需要先对齐" —— 把球抛回去
- 指名要拉的人 + 指名要定的事——让对方无法再模糊化
- 短，3-5 行；长了像在讲道理

## 常见陷阱

- **越解释越显能**：解释"为什么我不懂"会暴露你其实懂——说一句就停
- **替对方拉人**：你主动拉了就是接了协调责任。让**他**去拉
- **会上手痒给方案**：忍住。会上只问问题，不下方案。等会议纪要写他定的目标，你再围绕执行层走
- **DM 越线"建议怎么定"**：私下给建议会被截屏当"你已经认可这个方向"

## 和 Memory 的配合

- 档案 `#profile` 标对方"决策权高 / 不行使" / "摘果型" → 直接默认本策略
- `#strategy (outcome:: ✗)` 历史是"我硬扛了" → 强烈提示切本策略
- `#strategy (outcome:: ✓)` 上次本策略已成功 → 复用（同 scenario）

## 分支预判 hint（reply-coach §9 用）

对方对本策略的常见反应：

- **分支 1（高概率）**：他真的去拉会议 → 你参会 / 不主动决策 / 等他定了再承接执行 → 后续按会议纪要的 owner / 时间推进
- **分支 2（中概率）**：他说"你来定就好" / "你看着办" → 你的下一句："这个范围超出我能 own 的部分（list 具体哪些点不在我职责内），还是得 [具体的人] 来定"——继续抛回
- **分支 3（低概率）**：他急了 / 强压"这就你来"→ 升级到 olden-patterns §7 公开施压 → 切策略 B 公开冷处理 + 私下定界
- **超过 2 步**：脱离 reply-coach scope，走现实策略（找你自己 leader 同步 / 走文档留痕 / 拉 HR 边界）
