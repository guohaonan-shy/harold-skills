# 去情绪化 + 切回事实（defuse-emotion）

## 适用

- 对方使用情绪绑架话术：把感情 / 失望 / 愤怒 / 羞耻当作论据来推动你
- olden-patterns §8 情绪绑架："你怎么连这个都不懂" / "我对你太失望了" / "你这样让我很难做"
- 对方把"分歧"包装成"你不重视我 / 你不在乎团队"
- 你觉得这条消息让你**心里堵 / 想认错 / 想道歉** —— 这个生理反应本身就是情绪绑架成功的信号

## 不适用

- 对方是真的有情绪受伤而不是绑架（**这是关键差异，看 olden-patterns §8 vs 普通诉苦**） → 那要先听 + 共情，再切事实，不能直接切
- 关系层面真的需要修补（你确实有过失） → 先承认 + 道歉再切事实

## 应对剧本核心

**情绪绑架的杀伤力来自"你接情绪话术 = 默认事实未必成立但情绪是真的"**。一旦你接了情绪，对方就成功把讨论挪到"我感受 vs 你感受"层面，事实变成附带。

**第一句直接切事实**，**不接** "你觉得我不懂" / "我让你失望" 这类话。**不**说"我没有让你失望" —— 这是接了情绪话术。**说**"具体是哪个动作 / 哪条消息让你这样判断的？"——这是把情绪转回事实。

**核心三动作：**

1. **不接情绪话术** —— 第一句不出现"我没有 X" / "我也很难过 / 我也很在乎"等回应情绪的话
2. **要求事实化** —— "具体是 [哪个时间 / 哪条消息 / 哪个动作] 让你这样判断的？"
3. **拿到事实后回归就事论事** —— 走 reply-factual.md 的结构（事实定位 / 拆点 / 提议动作）

**关键句式**：

> "我想理解你这条信息的具体所指。能不能告诉我是 [时间] 哪个动作 / 哪条消息让你有这个感受？"

或者更短：

> "这个判断基于哪个具体事实？"

## 3 候选差异维度

- **A. 保守版** —— 一句温和但坚定的事实化要求："我想认真回应你的感受，能不能告诉我是 [何时 / 何事] 触发的？我们具体聊一下"
- **B. 标准版** —— 直接事实化："这个判断基于哪个具体事实 / 哪条消息？我们对一下事实再说"
- **C. 微刺版** —— 直接拒绝接情绪话术："情绪部分我先放一边，我们先把事实说清楚：[拿出你的事实清单]"

## 缺什么必须先 AskUserQuestion 问

- **对方原话** —— 没有原话不能精准判断"是情绪绑架还是真受伤"。要让用户**逐字贴**对方那条消息
- **关系背景** —— 你之前是否有过失？真有过失 + 情绪话术 → 切策略到先共情再事实，本策略不适用
- **场景是公开还是私下** —— 公开场合用本策略要更软（A 保守版），不然显得冷血；私下可以更直（C 微刺版）

## 措辞要领

- **不**说"我没有这样想 / 我也很在乎你" —— 接情绪 = 失败
- **不**反问"你为什么这样说" —— 反问会被解读为"你不在乎我"
- **不**用"理解你的情绪" / "感受到你的失望" 这类共情话术（**情绪绑架场景**下，共情等于让步）
- **要说**：用具体时间 / 文档 / 数字 / 行动 替代抽象的感受词
- **第一句最关键** —— 第一句没切回事实，后面再切就晚了

## 常见陷阱

- **替对方共情**：以为温柔回应能化解 → 反而强化"我可以用情绪推他"
- **过度澄清"我不是这样的人"**：每次都自证，对方学到"按这个键能让你解释半天"
- **混淆"真情绪受伤" vs "情绪绑架"**：受伤要先共情，绑架要切事实。看 olden-patterns §8 判断
- **用很多事实"反击"** ：堆数据反击 → 进入辩论 → 失败。要事实**精准**不堆量

## 分支预判 hint（reply-coach §9 用）

- **分支 1（高概率）**：对方给不出具体事实 → 自动暴露这是绑架 → 你保持事实问句不变 → 对方往往会软下来或撤退
- **分支 2（中概率）**：对方给出一些事实 → 你按事实正常对话（切到 reply-factual.md 模式）→ 关系回到正常
- **分支 3（低概率）**：对方加码情绪 / 升级公开 → 切到 §3 公开施压 → 用策略 B 公开冷处理 + 私下定界
- **超过 2 步**：对方持续情绪绑架不接事实 → 脱离 reply-coach，走真实策略（同步 leader / HR / 拉关系层面对话）
