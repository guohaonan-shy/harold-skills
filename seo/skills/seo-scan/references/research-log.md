# 研究日志的摘要模板

`seo-scan` 的「研究日志」一节第 2 步照这个写到 `<运行目录>/log.txt`。`wc -m` 不超过 1000 字符（`appendResearchLog` 的上限）；超了先把 issue 标题删成只留编号，再把拒收原因合成一句。前两行的格式不能改：`seo-due.mjs` 读以前各次扫描「采集」那一行。

```
seo-scan <YYYY-MM-DD HH:MM>，方向：<方向...>
采集：<方向> <N> 条；<方向> 未采集（<原因>）；…
花费：<n | 未知> credits，余额 <n | 未知>；预算跳过：<方向（原因）| 无>
同步：<seo-context 的 summary | 无改动 | 失败：原因>
新建：#<号> <标题>；…（无则写「无」）
评论：#<号> <标题>；…
拒收：<标题>（<原因>）；…
<untyped 为 true 时加一行：项目没有 seo 分类，跑一次 seo-setup>
<提 issue 失败时加一行：提 issue 失败：原因>
```
